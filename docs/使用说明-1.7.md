# 雀友计点 1.7

作者：HMBlankcat。安卓 8.0 及以上，离线适配雀魂四麻／三麻。本版沿用签名，可直接覆盖 1.6.0 并保留原输入、对局与练习成绩。README 本次未修改。

## 牌效率分析

从「看牌算分」顶部点「牌效分析」，或点「分析当前手牌」直接带入手牌、面子、宝牌指示、风位和拔北。也可从「练习」进入。分析输入独立保存，不改算点输入和对局余额。

录入摸牌前 13 张或摸牌后 14 张；自己的吃碰杠分开录入，每组按 3 张折算，杠多一张。可用下拉框切换手牌、面子、宝牌指示和其他已见牌。点已录入牌删除；支持粘贴 123m456p789s12344z 这样的牌谱，0 表示赤五。已见牌不要与自己的手牌、面子、拔北或指示重复。

输入完整后自动列出向听数、每种舍牌的有效进张、剩余张数和优选。默认先最少向听，再最多进张；13 张时只看当前手牌。已完成形会提示先检查能否和牌。

「计算好形率与 EV」按需计算，支持未来 4／8／12 次自摸、64／128／256 次模拟。可切换为按模拟 EV 排序。好形定义为至少两种、合计至少六张剩余和牌张，计算到一向听；不专指两面。EV 是固定进攻模型下的自摸收入估计，不含荣和、放铳、防守、振听、对手速度或立直千点支出，不等于实战净收益。详细假设与误差解释在页面中可展开查看。小幅差异不宜当作绝对优劣。

## 何切练习

从「练习 → 何切练习」进入。内置 720 道独立生成、校验的牌效题，四麻与三麻各 360 道，每种规则各有 120 道听牌、一向听、两向听取舍题。可按规则与类型筛选，顺序／随机作答，或输入题号跳转。

点选手牌后提交。先比较舍牌后的向听数，再比较有效进张总张数；等价最优答案均接受。提交前隐藏答案，提交后显示正确舍牌、自己的选择、有效进张和全部舍牌比较。不按 EV、防守或顺位战略评分。

Xpilot 原经典题库受单独授权限制，本版使用独立的 720 道牌效题，未搬运原题或原解析。来源与生成方法在源码 docs/算法与题库说明-1.7.md 中说明。

## 清一色听牌训练

从「练习 → 清一色听牌」进入，选择随机／万／筒／索和难度：基础 2–3 面、进阶 4–6 面、挑战 7–9 面。自动随机生成合法的 13 张门前听牌，选择所有和牌张并提交。赤五与普通五按同一数字判断。

全部选对且不多选才计对；答案列出遗漏、多选、总等待数及剩余张数。每种正确答案都可展开一种合法拆牌示例。排除第五张假听牌，包含普通形与七对子。

## 保存与清理

何切与清一色分别保存已答、答对、正确率、当前／最长连对；何切保留题号进度，仅保存汇总，不保存逐题历史。跳过题目不计分，每次呈现只记一次成绩。可在训练页单独清除这两类训练成绩；原「清除成绩」仍只清除点数／符数练习。

「牌谱 → 管理本地数据 → 清空全部本地数据」会同时清理牌效输入、所有训练成绩和原有对局、算点输入、指南进度。内置题库属于安装资源，不占用历史记录缓存。对局 JSON 备份不包含训练成绩或牌效输入。
