# 1.7 牌效与训练来源说明

本次功能需求参考用户提供的 Xpilot 项目（https://github.com/fyisvia/Xpilot ，项目网站 https://mj.fyisvia.com ，作者 Fyisvia Virell）。提供的项目以 AGPL-3.0 及附加条款授权代码，明确排除题库、内容集和媒体的再分发许可。

雀友计点 1.7 的 efficiency.js、efficiency-ui.js、efficiency-worker.js、training.css 和 discard-bank.js 均为独立实现／生成，未包含 Xpilot 的代码、原题库、文本解析或媒体，也未使用其 EV 估算器。原项目的 600+ 经典题未收录；本版为独立的 720 道纯牌效练习（四麻 360、三麻 360），不应宣传为原经典题的移植。软件沿用自身的牌面、算点引擎与界面。

题库生成器：tools/generate-discard-bank.cjs。固定种子 20261115，以面子与对子构成候选牌形，再扰动、筛选和校验；三类分别为舍牌后 0、1、2 向听，每类每种规则 120 题。按最少向听、最多有效进张评分，等价最优答案全部接受。题目不评价牌价、防守、顺位或巡目战略。

清一色：随机构造完成形、移除一张，枚举九种数字验证等待；限定每种最多四张。按 2–3／4–6／7–9 种等待分层；随机重试不足时使用完整枚举寻找符合难度的新题。包含普通形与七对子，赤五按五判断。

向听：枚举各花色与字牌的面子、搭子、雀头前沿，再合并；同时计算七对子、国士（存在已声明面子时禁用特殊形）。四枚同牌不能要求第五张，进张扣除手牌、自己的面子、宝牌指示、拔北、其他已见牌。舍出的牌仍属于已知牌，不能放回未知池。

好形率：好形定义为至少 2 种有效和牌张、剩余总张数至少 6 张，是广义宽等待，非专指两面。听牌结果为 0 或 100%；一向听按有效摸牌张数加权，摸进后允许选择能达到好形听牌的弃牌。更高向听显示不适用，避免将不同定义混为一谈。

EV：未来 4／8／12 次自摸，64／128／256 次确定性伪随机采样；未知牌无放回抽取，弃牌不返池。固定策略优先向听，再按宝牌与连接性打破平局；并非全局最优策略。完成后用原有雀魂引擎计算真实自摸收入，未和牌计零。门前完成按立直计番，未模拟宣言、锁手和千点支出；无一发、里宝、本场供托。模拟中不开新杠、不吃碰、不拔北，不模拟荣和、放铳、防守、对手或振听。输出均值、和牌比例及近似采样误差；零次观察到和牌时提示样本不足。不能把模型估计当作实战净收益或胜率。

外部校验：开发时与独立 Python mahjong 参考实现比较 3000 副随机牌及题库全部 7962 个原手牌／舍牌状态的向听数，结果一致。参考库只用于开发核对，不随 App 分发。清一色题等待与现有雀魂算点引擎独立交叉验证。
