# 术语表

## 待掌握

**数牌**: 万、筒、索三种花色的1至9。简记 m、p、s。

**字牌**: 东南西北白发中。简记 z 时采用东南西北白发中的顺序。

**面子**: 顺子或刻子；杠子按一个面子计。

**雀头**: 标准和牌结构中的一对相同牌。

**役**: 允许和牌的规定条件；宝牌本身不算役。

**役牌**: 白发中、自风或场风组成的刻子或杠子；同一风兼自风与场风时可兼计，只有对子并未成立役牌这个役。

**翻**: 表示役及宝牌加值的计分单位；普通和牌先满足至少一项役，再合计翻数。

**符**: 反映牌组、等待及和牌方式的计分单位，与翻一起决定普通和牌点数；固定符和取整另有规则。

**宝牌**: 能增加手牌翻数的牌，通常包括表宝牌、赤宝牌和里宝牌；宝牌本身不提供普通和牌所需的役。

**役满**: 满足特殊条件的高价值役，按役满等级结算，不与普通翻数直接相加；倍数、复合及责任支付依规则核对。

**门前**: 未吃、碰、明杠的状态；暗杠保留门前。

**向听数**: 距听牌所需的最少结构改善次数；听牌为0向听。

**进张**: 摸入后能降低向听数的牌；枚数扣除自己手牌和已知明牌。

**立直**: 门前听牌时满足条件作出的宣告，之后的动作受规则限制。

**振听**: 符合条件时禁止荣和的状态，合法自摸仍可成立；避免泛称“不能和”。

**现物**: 针对某一家，其舍牌等规则条件保证不会被该家荣和的牌。

**筋**: 利用两面等待及振听条件作出的风险推断，不能保证安全。

**壁**: 已见牌形成的枚数限制，可减少部分顺子等待可能。

**押引**: 在进攻与防守之间作出选择，也称攻守判断。

**牌谱**: 对局过程的记录，用于在决策时信息范围内复盘。

**听牌**: 手牌再补入某一种牌即可形成完整和牌结构的状态；能否实际荣和还需检查役、振听等条件。

**自摸**: 用自己摸入的牌完成和牌，也指这种和牌方式；合法性仍须按规则检查。

**荣和**: 用他家舍出的牌，或规则允许抢杠的牌完成和牌，通常也写作“荣”。

**副露**: 吃、碰与明杠等把他家牌纳入自己公开牌组的动作；暗杠不使手牌失去门前资格。

**搭子**: 差一张即可组成顺子的两张数牌；本教程将对子另外列出，以免拆分时重复使用同一张牌。

**孤张**: 在当前选定的拆分中，尚未归入面子、搭子或对子的单张牌；其价值取决于后续成块、役和安全用途。

**两面**: 可由两侧的牌补成顺子的等待，例如23万等待1万或4万。

**嵌张**: 等待两张数牌之间一张牌的形状，例如35筒等待4筒。

**边张**: 12等待3或89等待7的顺子等待；不能把所有含1或9的等待都称为边张。

**双碰**: 两个对子分别等待第三张同牌，其中一个组成刻子，另一个作为雀头的等待。

**单骑**: 以一张牌等待同种牌组成雀头；完整等待应结合整手牌的其他拆分检查。

**复合形**: 同一片牌可形成多种面子、搭子或对子拆分的组合；各种拆分之间不能重复使用实物牌。

**改良**: 摸入后向听数不变，但可能改善后续进张、最终等待或手牌价值的变化。

**受入**: 常作进张的同义语；本教程计数时指能降低向听数的牌，同向听改良和听牌后的等待另行列出。

**打点**: 手牌和牌时的得点水平；比较时需说明役、宝牌、庄闲及荣和或自摸等条件。

**默听**: 门前已经听牌而未宣告立直的状态，也称“暗听”；是否有役、能否荣和要另行判断。

**片和**: 在当前役与门前条件下，多种等待中只有部分和牌牌种满足至少一役；对每种完成方式分别检查，条件改变后重新判断。

**食下**: 某个役允许副露，但副露后翻数减少一翻；不等同于所有役都会因副露而减翻。

**供托**: 放在桌面、按规则由和牌者等取得的点棒，常见为立直棒；计算点差时应与支付额分开记账。

**本场**: 表示连续对局结算进程的计数，可能带来额外支付；增加、重置和支付方式须按具体规则核对。

**连庄**: 同一名玩家下一局继续担任庄家；成立条件与终局处理依对局规则而定。

**结果偏差**: 事后根据输赢、放铳或后续摸牌评价原先选择，却忽略决策时实际可知的信息。


**补块**: 将孤张或不完整材料发展为可用的面子、搭子或对子。

**候补块**: 尚未完成、准备用来承担某个结构职责的材料，不能当作已完成块。

**路线转向**: 随材料、信息或目标变化，重新安排最终结构与役的职责。

**对子手**: 含较多对子、需要比较对子作头、成刻或七对用途的手牌描述，不是新增役。

**死对子**: 自持一对、其余两枚已见而不能再成刻的对子，仍可作雀头。

**染手**: 围绕一种数牌花色构筑混一色或清一色的路线。

**外色牌**: 目标花色以外的数牌；字牌仍可进入混一色。

**混一色**: 完成牌只使用一种数牌花色与字牌的役，门前3翻、副露2翻。

**清一色**: 完成牌只使用一种数牌花色且没有字牌的役，门前6翻、副露5翻。

**宝牌靠张**: 能与宝牌形成搭子、顺子等结构的邻近数牌，本身不提供加翻。

**手役复合**: 同一最终和牌解释同时满足多项可兼计役，逐项检查结构与门前条件。

**形听**: 以取得或维持流局判听为主要目的的听牌，是否判听依具体规则或题设。

**荒牌流局**: 正常牌山按规则摸完、仍无人和牌而进入的流局事件。

**不听罚符**: 流局时未听方向听牌方支付的点数转移，与和牌符数不同；总额与判听依规则。

**手出**: 舍出原暗手中已有的牌。

**摸切**: 舍出刚摸入的牌。

**生张**: 在当前观察范围内未见同种牌的牌，不说明必在牌山或必然危险。

**小三元**: 两种三元牌成刻或杠、第三种作雀头的2翻役，役牌刻子可另兼计。
