# 实验一：基础牌例册 · 深化自查

先按以下要点找缺项，再打开独立答案；不是依据关键词自动判掌握。

## 补充1 · 牌数状态与延单骑的合法性

- A1/A2计数、全部等待、合法役、舍牌振听整组限制、临时解除与立直后持续限制均须有独立依据。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 先把固定面子画在暗牌之外；延单骑每条完成都要确定雀头。振听的不同来源不要互相覆盖。

## 补充2 · 固定符、荣和明刻与逐家账目

- 固定20与25符正确；普通荣和/自摸的明暗刻、翻数和符同时更新；每笔支付独立进位；本场供托账目完整。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 先问是不是固定符；普通形再看最后一张到底补成明刻还是暗刻。桌面供托不能再次向某位对手扣除。

## 补充3 · 进张按实体去重并检查役分支

- 完整进张并集、去重实体数、未见上限与每条役路线均对应同一舍后状态。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 同一枚2p从甲河移入乙副露，只占一个实体。先枚举四种进张，再一行一行扣数。

## 补充4 · 特殊形与孤张覆盖的两种比较

- 不漏七对子；四枚同牌不能算两种对子；自由暗牌与固定副露有别，不能将局部结论升级成全手最优。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 标准形之外单独数不同对子；局部功能比较先确认手中资源是否真的可用。

## 补充5 · 安全矩阵与第四枚字牌的反例

- 对象和时点齐全；筋不是保证；拟舍第四枚字牌仍检查国士，额外条件必须针对国士所需幺九。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 先写谁自己舍过什么，再考虑筋能排除哪条两面。字牌数量要保留特殊形反例。

## 跨任务核对

- 实物牌与结构职责分开；同一枚牌不重复用、同一摸牌事件不重复数。
- 役、翻、符、支付、本场和供托按题设分列；按每名支付者取整。
- 安全与推断写对象和时点，结论强度不越过证据；策略允许有条件替代。
- 原答、订正、后续新例分开，未发生的日期与结果留白。
