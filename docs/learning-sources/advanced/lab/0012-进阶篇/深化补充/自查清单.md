# 实验二：进阶决策册 · 深化自查

先按以下要点找缺项，再打开独立答案；不是依据关键词自动判掌握。

## 补充1 · 完全一向听和计划外的新分支

- 六种进张无重复，残枚实体扣除正确；两个分支保持合法13张；新两面和重叠牌更新清楚。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 每条分支先恢复原手；一对进成刻后，谁接替雀头？旧拆块计划需要随新牌更新。

## 补充2 · 解决急所与后付路线的保证

- 鸣后实物、等待和30符一翻正确；比较最终等待而非只看降向听；后付许可和最终成役分开。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 两条都到听还不够，写出剩下的薄弱块。役牌暗刻并不因吃了另一组就统一变成明刻。

## 补充3 · 无役默听与立直棒的两种基准

- 普通荣和资格清楚；两个等待的确定翻数分别算；本场、自己供托、终局与未来风险各有记录。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 无役门前不等于可荣和。排名题从宣告前或宣告后记账均可，但自己的棒不能当作额外利润。

## 补充4 · 三家威胁下的库存和首次风险

- 新增对象和已耗资源都更新；1p新增乙依据且对丙有依据；8m筋不能升级成现物，后续收益保留条件。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 共同安全要逐列求交集。第一枚没通过前，不能预支第二枚的收益。

## 跨任务核对

- 实物牌与结构职责分开；同一枚牌不重复用、同一摸牌事件不重复数。
- 役、翻、符、支付、本场和供托按题设分列；按每名支付者取整。
- 安全与推断写对象和时点，结论强度不越过证据；策略允许有条件替代。
- 原答、订正、后续新例分开，未发生的日期与结果留白。
