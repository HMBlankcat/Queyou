# 四人立直麻将 · 练习册说明

## 载体与开工

你只需要本教程、纸笔或能打开Markdown的编辑器。无需安装软件，也无需编写程序。先打开[完整牌例练习册](牌例练习册.md)，或按下表进入相应篇；答案独立放在solutions中，做完一段才对照。

任务中的可见牌、点差、巡目和规则是给定条件；未说明对手暗牌时不要补猜。数牌统一m万、p筒、s索，字牌用中文。只写整数的字段不带单位；等待字段按任务单给定的半角逗号格式。纸笔作答无需拘泥文件格式，保留编号即可。

## 分步与卡壳顺序

每段只做一至两项：抄清已知条件，填写候选与依据，当场按任务自查项核对，再进入下一项。完整实验可分段完成，每段建议不超过10分钟。

1. 先定位具体缺项：牌数、役、振听、符、支付还是安全对象。
2. 再回看对应课的带解例和任务单要点。
3. 还卡住时向学习总控索取提示，再索取线索；最后才翻参考解。

保留最初作答与订正，不要覆盖错误。延迟复测栏留给隔天或更晚的新例；空白并不表示已经验收。正式实验验收逐项引用学生真实证据，不用备课参考解代替。

## 可选的材料自检

以下是给备课维护者的可选检查，不影响纸笔使用。自检沿用插件lab骨架的check.sh，断言只核对字段留白与少量指定格式的客观值；它不会判定理由质量、策略唯一最优或学生掌握。POSIX sh及基本命令可运行时，在各篇任务目录执行sh check.sh；没有该环境就按上面的自查项人工核对，不要求学生安装。

根目录的干净态.sh、作答态.sh、自检.sh逐字来自骨架，默认只挑字典顺序第一篇（基础篇）。骨架没有多篇选择参数，不能把根自检当成三篇都跑过。维护者若需逐篇重跑，可把一篇任务与其同名答案单独复制到本会话临时目录，再原样运行骨架自检；本次交付已对三篇分别这样检查。

干净态保留留白，预期读到空格并返回非零；作答态把参考解放到临时副本，应读到对应字段并返回零。退出码仅是运行事实；自检不写入进度，也不会代替语义核对。根脚本中的临时目录操作只用于维护者；本课程的学生任务仍是中文牌例册。

原三册13项保持原编号与原留白，新增加13项按各篇的“深化补充”目录单独作答。可从[深化练习总册](深化练习总册.md)离线阅读；[深化答案总册](solutions/深化答案总册.md)与任务分开，做完一段再对照。新题自主编写，依据已读的文字原则与开放作者教材，不还原未读图片里的牌例。

每项仍按读条件、亲手列式或拆牌、即时自查、完成后对照的顺序，较长任务可分成每段约5至8分钟。原答不覆盖，订正另写。对同一牌种的多条拆分只记录一次摸牌事件；安全结论逐家更新；点数把四家与桌面池一起守恒。

补充答案位于solutions/对应篇/深化补充/作答/深化册.md，内容自包含。新作答页的真实日期、原答、订正和未来独立复查保持留白。未完成的新例不能凭材料已准备就记作通过。

## 深化材料的可选字段检查

学生仍只需纸笔。维护者如已有POSIX sh环境，可在各篇的深化补充目录用原骨架check.sh读取该补充的作答/深化册.md及探针/字段.tsv。入口框架沿用插件骨架，字段断言沿用原册形式；原册的check.sh、作答/与探针/没有改动。根目录自检的选择范围仍按上文说明，不能用它替代三套新增补充的分别检查。

每套新补充的干净留白态与参考作答态应在scratch隔离副本分别运行：留白态预期有空字段、非零退出；参考态预期读到相应固定字段、零退出。检查不会覆盖正式学生作答，也不核定开放理由、策略最优、段位或掌握。脚本事实与人工语义对照均只属于备课检查。
