# 实验三：高手研修册

载体：纸笔或Markdown。直接写在作答页；不要求运行脚本或安装软件。建议分段完成，每段不超过10分钟；整册约15至25分钟，这只是材料安排，不代表你的可投入时间。

约定：m万、p筒、s索；字牌直接写中文；同种最多四枚。所有数值规则是本题条件，并非宣称雀魂当前全部设置已核验。先独立作答，再看分开的参考解。

## 任务1 · 条件化押引

题目直接给定状态，不反推完整暗牌：南一局闲家第十巡面对庄家立直，自己已听，保证满贯，两面未见上限八枚。继续需舍无安全保证的5m；转守可舍9p，但手中只有这一枚共同现物，其他安全资源未知。A1写两个可执行动作及成本。再分别改为“1向听、进张六枚”和“5m成为共同现物”，A2写怎样更新，保留合理替代。

要点：不能把满贯路线当保证满贯，也不能把一枚现物当全局防守。

做完自查：写价值、速度、未来危险牌、庄家威胁、防守可持续性与未知量；不用虚构概率。

## 任务2 · 末局逐人账

自己22600、目标28000，都是闲家；庄34400、另一家14000，桌面一根已有供托。一本场，荣和加300、自摸每家加100；自己和牌即终局，同点自己居后。B1填初始点差整数。B2至B4分别写三条路线的自己/目标新点数和能否超过：直击目标基础2000；旁家荣和基础3900；闲家自摸基础1000/2000。B5写供托与终局条件。

要点：个人收入和对目标点差改善分开；三条路线都从当前点数重算。

做完自查：直击和旁家对目标支出不同；自摸分庄闲；不再向任何一家扣供托。

## 任务3 · 读牌的反证

某家公开白白白、123s、789s，舍牌后暗牌四张，未给更多牌河和可见枚数。有人说“必为混一色，所以万子一定安全”。C1把事实、规则结论、推断、未知分别写一条；C2给出能荣和万子的兼容四张暗牌及等待，并说明反例的作用和限度。

要点：公开花色不是精确暗牌；反例也须牌数合法且有役。

做完自查：例子确实是13张，白刻子有役；反例只排除绝对断言，不证明概率大小。

## 任务4 · 遮结果复盘

第六巡，无威胁、点差普通、无宝牌，14张22m445p123s789s中中中，其他位置未见相关等待。原舍一张4p，替代舍5p。先遮住后句：后来别人打2m，替代本次能和。D1写原/替代完整等待及上限；D2评价当时理由与后来结果；D3写一项新例训练任务、记录字段和延迟复测方式。

要点：先还原当时合法候选，再揭示结果；不要给反事实安排确定未来。

做完自查：两面八枚与双碰四枚正确；结果和理由分栏；后续任务可在新的日期与牌例检查。

## 收尾与订正

保留最初作答，另写订正原因；没有错误也要写明核对过的依据。把不确定信息标为未知，不能补猜对手暗牌。下面的自查只能帮助找缺项；正式实验验收还需要你的原始作答与隔天或更晚的新例复测，备课参考解不能代替你的证据。

最可能卡住时：先查牌数和条件，再回到相应课的带解例；仍卡住时只索取提示或线索，最后才对照答案。
