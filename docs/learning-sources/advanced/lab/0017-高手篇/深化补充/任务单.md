# 实验三：高手研修册 · 深化补充

载体为纸笔或Markdown。每项按“读已知→亲手列式或拆牌→自查→完成后对照”的顺序做；一项可分成数段，每段约5至8分钟，时间只是材料安排。数牌m万、p筒、s索，字牌汉字。同种最多四枚，所有数值与规则均为本题条件，未宣称雀魂当前平台细项已核验。

本补充册与原任务并列，使用自己的作答页，原册答案与历史不必搬动。题目是自主编写的教学材料；未读推荐牌图不作为牌例来源。填写数字字段只写整数，等待/进张字段采用半角逗号；其余字段用自己的话说明。纸笔只需保留编号。

## 补充1 · 完整结局表与条件变化

这是虚构算术模型，不是任何房间统计。采用单一和牌等使五类结局互斥且完整的题设，个人净变化依次为自和+8000、自己放铳-8000、他家相互荣和0、他家自摸-2000、流局-1000。进攻A五概率为0.20/0.10/0.30/0.20/0.20，转守B为0/0.02/0.38/0.30/0.30。填A1进攻期望、A2转守期望、A3两者差。另只在A模型中将自和收入提高1000、所有概率和其他结果不变，A4填期望增加量。A5说明真实押引为何不能只凭此模型、以及若当前危险舍牌突然成为共同现物，哪些成本和概率仍须重估。

要做出的记录：A1、A2、A3、A4、A5。

要点：先检查每组概率之和，再按同一收支口径加权。增加保证打点和增加平均每局收益不同。

做完自查：覆盖全部结局、算术和口径正确；模型假设与真实局况分开，说明防守也可能失点及后续风险。

## 补充2 · 四家账目、必要得点与自己的供托

题设：自己21800、目标27600、庄34600、另一闲家15000，桌面已有一根供托1000；自己与目标均闲家。一本场，荣和加300、自摸每家加100，不切上，自己和牌即终局、同点自己居后。基础荣和候选仅2000/2600/3900/5200，B1填直击目标的最低候选，B2填从另一闲家荣和的最低候选。B3列三条相互独立路线的四家和桌面最终值并判断：直击2600、从另一闲家荣和3900、自摸1000/2000。另一个独立变式：自己先付1000立直，随后从另一闲家荣和，最终基础点已确认3900，其他条件相同；B4填最终自己现金并说明基准。再独立改为荒牌流局，供托留桌，总额3000，自己唯一听牌、庄家与目标和另一家均未听，题设庄家未听即终局；B5列账和目标差，不将和牌的供托领取规则搬入流局。

要做出的记录：B1、B2、B3、B4、B5。

要点：每条路线恢复原点数。四家现金与桌面池合计先后均为100000；自己的新棒先付后取回，不能凭空增加收益。

做完自查：必要得点、三种支付、自己供托基准、流局分组和终局规则完整；逐家守恒后再排目标关系。

## 补充3 · 候选暗牌的数量更新与价值分支

某闲家无杠，公开中中中、123p、789p，舍后暗牌四张。先不假定更多牌河、宝牌或过程役。演示候选为①45p白白、②66m南南、③55s东东、④666m5s。C1分事实、规则保证、推断、未知各写一条，C2核对四个候选的完整等待。新增事实：自己与公开区合计已见三枚5s，其中含准备舍的一枚。C3更新候选并解释5s是否已安全、未知一枚在哪里。C4只针对①且暂不计未给加值，分别列3p/6p完成的役；说明这些候选和公开价值能否穷尽全部暗牌或确定整手上限。

要做出的记录：C1、C2、C3、C4。

要点：数量信息可排除持两枚的候选，未必排除持一枚的单骑。公开一翻和实际只值一翻不是一回事。

做完自查：每个反例四张且与公开面相容；数量排除准确；役分支正确，推断不越过证据边界。

## 收尾与卡壳顺序

先核对牌数和时间点；再回对应课的带解例；仍卡住时向学习总控索取提示，再索取线索，完成后才看参考解。字段缺失仅说明记录未齐，策略答案不以关键字出现与否判断。

保留初答、订正与依据；另一天换新例作答的日期和内容由学生填写。当日订正、读过解析或材料自检不单独构成独立掌握证据。正式验收应逐条对照本册及前置节点目标，缺核心点就列缺项。
