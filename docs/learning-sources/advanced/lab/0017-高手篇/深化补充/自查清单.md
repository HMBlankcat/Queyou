# 实验三：高手研修册 · 深化自查

先按以下要点找缺项，再打开独立答案；不是依据关键词自动判掌握。

## 补充1 · 完整结局表与条件变化

- 覆盖全部结局、算术和口径正确；模型假设与真实局况分开，说明防守也可能失点及后续风险。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 先检查每组概率之和，再按同一收支口径加权。增加保证打点和增加平均每局收益不同。

## 补充2 · 四家账目、必要得点与自己的供托

- 必要得点、三种支付、自己供托基准、流局分组和终局规则完整；逐家守恒后再排目标关系。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 每条路线恢复原点数。四家现金与桌面池合计先后均为100000；自己的新棒先付后取回，不能凭空增加收益。

## 补充3 · 候选暗牌的数量更新与价值分支

- 每个反例四张且与公开面相容；数量排除准确；役分支正确，推断不越过证据边界。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 数量信息可排除持两枚的候选，未必排除持一枚的单骑。公开一翻和实际只值一翻不是一回事。

## 补充4 · 四格复盘、抽样与另日新例

- 等待与计数正确；四格独立于输赢；比例有分母；新例计划可执行且日期、原答不由备课人填写。
- 对照每个字段的具体原答，指出计算或条件依据；缺项写明缺在哪。
- 有根据却没和、错误理由却通过都可能发生；统计要用相同机会定义。新例的实际执行留给学生，参考解不是已发生证据。

## 跨任务核对

- 实物牌与结构职责分开；同一枚牌不重复用、同一摸牌事件不重复数。
- 役、翻、符、支付、本场和供托按题设分列；按每名支付者取整。
- 安全与推断写对象和时点，结论强度不越过证据；策略允许有条件替代。
- 原答、订正、后续新例分开，未发生的日期与结果留白。
