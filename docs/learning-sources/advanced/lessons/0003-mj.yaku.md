## 先给路线命名

上一课已把合法和牌分成结构、役和取得方式。本课把**役**组织成可操作的手牌路线：目前靠什么取得资格，哪些条件还未完成，鸣牌后哪些条件会消失。

**翻**是普通役与宝牌用于计分的单位。先确认至少一个役，再加宝牌；“宝牌三枚”并不是一个可以直接和牌的路线。**门前限定**表示吃、碰、明杠后该役不再成立；**食下**表示副露后仍可成立，但比门前少一翻；有些役允许副露且翻数不变。

## 三条起步路线

| 路线 | 成立条件 | 使用时的边界 |
| --- | --- | --- |
| 立直，一翻 | 门前听牌后满足规则并正式宣告 | 仅有门前、仅有听牌都不等于已立直 |
| 门前清自摸和，一翻 | 门前并以自己摸入的牌合法和牌 | 门前荣和没有这一翻 |
| 役牌，每项一翻 | 白发中、自风或场风组成刻子或杠子 | 对子未成立役；风牌须读本局身份 |

东场南家，东是场风、南是自风，二者各自刻子都可提供一翻；白发中刻子不受座位影响。西、北若既非自风又非场风，则没有役牌翻，称**客风**。若同一风兼自风与场风，称**连风**，同一刻子可计两项役牌。例如东场庄家的东刻子可得两翻。

役牌对子只是未来路线。若两枚白以外的两枚都已公开，它不能再碰成白刻；自己仍可把它作雀头，但那是结构用途和符的用途，不能当作已有役牌翻。记录“已有役”与“未来可能有役”能避免此类混淆。

## 平和的四项检查

**平和**一翻，要求门前、四组顺子、非役牌雀头，并以两面等待补完顺子。四项同时满足，才可成立。检查时还要看最后这张牌在哪个合法拆分里完成什么。

| 完成条件 | 是否满足平和 | 原因 |
| --- | --- | --- |
| 四顺子、数牌雀头、门前，`23m`以1万完成 | 可以 | 1、4是两面，含1并不妨碍平和 |
| 同上，但雀头为白 | 不可以 | 白属于役牌雀头 |
| 同上，但`35m`以4万完成 | 不可以 | 以嵌张完成 |
| 四顺子但已经吃过一组 | 不可以 | 平和门前限定 |
| `1234m`以1万补成`11m、234m` | 不可以按此等待取得 | 最后一张补雀头，是单骑解释 |

客风雀头可以满足平和的雀头条件；同一种风换一个座位或场次可能变为役牌，必须重查。没有刻子只是其中一项，不能替代全部条件。

**断幺九**一翻，要求全手仅2至8数牌。它与平和检查不同：平和可含123、789，断幺也可含刻子。副露断幺称**食断**，是否采用按规则；本教程涉及食断的例子会明确假设允许。

**一杯口**一翻，门前有两组同花色同数字的顺子，例如两组`234m`。这是两组实物顺子，共六枚牌；一组`234m`不能数两遍。它可与平和、断幺等相容，但先保持门前。

## 常用形状役速查

本表给出成立入口。先熟悉常用路线，遇到较复杂役再逐项核对，不要求在第一遍阅读时背完所有名称。

| 役 | 门前／副露翻数 | 结构条件 |
| --- | --- | --- |
| 七对子 | 2／不可 | 七种不同对子 |
| 对对和 | 2／2 | 四组刻子或杠子加雀头 |
| 三色同顺 | 2／1 | 三种花色各有同数字顺子 |
| 一气通贯 | 2／1 | 同一花色有123、456、789 |
| 混一色 | 3／2 | 只用一种数牌花色与字牌 |
| 清一色 | 6／5 | 只用一种数牌花色，无字牌 |
| 混全带幺九 | 2／1 | 每面子与雀头含幺九，且有顺子、有字牌 |
| 纯全带幺九 | 3／2 | 每面子与雀头含数牌1或9，有顺子、无字牌 |
| 三暗刻 | 2／2 | 三组暗刻或暗杠 |
| 三杠子 | 2／2 | 三组杠子 |
| 三色同刻 | 2／2 | 三种花色各有同数字刻子或杠子 |
| 小三元 | 2／2 | 两组三元刻杠、另一组三元雀头；另计两组役牌 |
| 混老头 | 2／2 | 全手仅幺九，没有顺子；可兼对对和或七对子 |
| 二杯口 | 3／不可 | 四顺子形成两对相同顺子，不再加一杯口 |

**暗刻**指不借他家来牌完成的刻子。荣和补成的一组刻子在三暗刻和计符中按明刻处理，但整手若未副露，仍保持门前。例如门前双碰荣和，不能仅凭三组原有刻子加新刻子就说四暗刻；自摸与荣和完成方式要分开核对。

七对子与标准形可能共存多种解释，但不能在同一计分解释中把七对子、平和、一杯口机械相加。二杯口按四顺子解释时，也不再追加七对子。相反，七对子可以与断幺、混一色等符合整手范围的役复合。

## 不同等待分开判

门前十三张`45m345p345s789s22p`，等3、6万。补3万时可组成三种花色的345，三色同顺成立；补6万成为456万，三色消失。两种完成方式都可符合平和，但价值不同。

假设普通荣和、未立直、无其他过程役与宝牌：3万有平和一翻与三色二翻；6万只有平和一翻。若已副露，平和消失，3万仍可能靠食下的三色一翻和牌；6万若再无其他役，就无役。这类等待一侧有役、一侧无役的情况，称**片和**，必须在每个和牌牌种旁标明。

役路线的保证程度可分三栏：“已经有”，例如固定的中刻子；“仍需完成”，例如白对子；“取决于等待”，例如上例的三色。片和不改变完整结构等待集合，舍牌振听仍不能只查有役的一侧。

## 副露前后算一次

门前十三张`23m456p678s中中55s9m`，他家刚舍中。碰中并舍9万后，公开中刻，隐藏`23m456p678s55s`，听1、4万。两侧均保留役牌中，副露路线已有保证。

若把中对子换成客风西对子，碰西后仍可结构听牌，却失去立直、门前清自摸等门前路线；这副含西刻子的手牌也不满足断幺、平和。三枚宝牌不能挽救无役。是否鸣牌须把“鸣后有什么役”写清，而非只写“向听降低”。

食下与失役也要分开：混一色门前3翻、副露2翻，仍有役；平和副露后消失，不能误记为从1翻减到0翻却仍保留资格。对对和和役牌则不因副露统一减一翻。

## 同手两侧逐项勾核

再看一个可以同时检查多个常用役的完整例：门前十三张`234m234p23s567s55p`，普通巡目、未立直、无过程役与宝牌，等1、4索。三组已完成顺子、一个55筒雀头与23索两面都能逐张定位。

| 完成牌 | 平和 | 断幺九 | 三色同顺 | 本例普通役合计 |
| --- | --- | --- | --- | --- |
| 1索 | 四顺子、数牌头、两面，成立 | 有1索，不成立 | 索为123，缺234索 | 1翻 |
| 4索 | 四顺子、数牌头、两面，成立 | 全手2至8，成立 | 万筒索都有234，成立 | 1+1+2=4翻 |

两侧同属两面完成，却有三翻差异。原因可以追到具体牌组：1索破坏全中张条件，也没有补出234索；4索同时满足两项。不能只写“高目四翻”，然后把两侧都按四翻估值。

现在另设234万已经作为公开顺子，其余结构相同，并明确允许食断。平和在两侧都失去；4索侧仍有食断一翻与食下三色一翻，共两翻；1索侧既无断幺也无三色，本例再无其他役，普通荣和无役。这是一次动作同时改变门前资格与分支保证的完整过程。

只要一侧仍有结构，振听检查就不能把它当作不存在。若自己此前舍过1索，不能以“我只打算和4索”为由忽略舍牌振听。选择目标牌种与规则规定的完整等待，是两种不同的事情。

## 两套解释分别结算

完整十四张`112233m445566p77s`，既可按七个不同对子解释，也可按`123m、123m、456p、456p、77s`解释。前一种提供七对子两翻；后一种提供二杯口三翻。两套解释各自使用全部14张，没有任何一张供另一套额外借用。

| 选择的解释 | 可以计入 | 不可追加的内容 |
| --- | --- | --- |
| 七个对子 | 七对子及符合全手范围的其他役 | 不能再取四顺子解释的二杯口 |
| 四顺子一雀头 | 二杯口及该解释下兼容的其他役 | 二杯口不再加一杯口，也不再加七对子 |

这副牌若最后荣和3万，四顺子解释中3万补的是12万边张，不能另得平和。七对子解释的最后3万则补对子，但不能把这个单骑解释的条件移到二杯口上。具体点数到下一课再算；本课先保证每条役清单内部一致。

## 路线改变要付代价

役路线有时可以自然重合，有时需要改变手牌。平和与断幺重合时，并不要求全手都没有1、9才可先取得平和；为了硬追断幺而拆掉完成的123，可能多付速度。三色已经有两种花色，也不保证第三种正好会来。

例如上面的1索侧已经有平和，4索侧价值更高；若1索合法出现，是否放过以等待4索，是取得方式、巡目、振听、点差与未来机会的共同问题。役表只告诉两侧各有什么，不能从翻数差直接推出必须见逃。非立直见逃会产生临时限制，立直后见逃会持续振听，均须与合法和牌课连接。

把路线记录成“保留哪些块、仍需哪种牌、成功后增加什么、失败时还能靠什么和牌”，比只列一个想做的大役更可用。当备用路线也已消失，例如副露后既无固定役牌又失去片和高侧的残枚，就应明确写出资格缺口，不能继续沿用鸣牌以前的门前潜力。

## 宝牌的三个来源

**表宝牌**由**宝牌指示牌**指向下一种牌。指示牌自身不因翻开就变宝牌。数牌1至9循环，风按东南西北循环，三元按白发中循环。

| 指示牌 | 对应宝牌 | 核对要点 |
| --- | --- | --- |
| 4万 | 5万，包括赤五万 | 指向下一数字 |
| 9筒 | 1筒 | 数字循环 |
| 北 | 东 | 风牌单独循环 |
| 中 | 白 | 三元牌单独循环，不与风混排 |

每持有一枚对应宝牌通常加一翻；重复指示同一种牌时可叠加。**赤宝牌**是规则采用的赤五，自身加值；若又被表宝牌指向，同一枚赤五可同时取得表与赤两项加值。

**里宝牌**是立直和牌后按规则揭示隐藏指示牌得到的加值，副露和牌不能因此自动看里。未来里宝牌、一发均未确定，临场估值要与已经保证的翻数分列。杠可能增加指示牌，也可能使对手加值。

## 过程役与役满

**两立直**通常在自己第一巡且无规定中断动作时正式成立，计2翻，替代普通立直；**一发**是在立直后规定的一巡内、未发生规定中断而和牌的附加1翻。二者均依过程成立，不能仅凭最终牌面断言。

**岭上开花**是杠后以岭上牌自摸，**抢杠**是对规则允许的杠动作荣和，**海底摸月**是有效牌山最后一张自摸，**河底捞鱼**是荣和相应最后舍牌，通常各一翻。适用动作、相互组合与特殊抢暗杠例外须按规则核对。流局满贯则是特定舍牌条件下的流局结算，和上述十四张普通和牌不同。

**役满**按特殊高价值等级结算，通常与普通翻数计价分开。常见识别入口是国士无双、四暗刻、大三元、四喜和、字一色、清老头、绿一色、九莲宝灯、四杠子及天和地和。绿一色仅用`23468s`与发；九莲宝灯为门前同一花色`1112345678999`再加该花色任一张。它们仍须形成合法结构并满足取得方式。

国士十三面、四暗刻单骑、纯正九莲或大四喜是否双倍，多个役满如何复合、是否累计役满及责任支付，均属于规则依赖事项。实战遇到时应查现行役表，不把罕见例外强记成普遍规则。

## 把役写进练习册

路线栏至少写役名、当前条件、未完成项、副露后变化与不同和牌牌种。初学时先保证一条合法路线，再比较能否自然增加断幺、平和、三色等价值；追求昂贵役时，同时记录增加了哪些步骤和失去了哪些完成机会。

::: practice 练习 | 给带解例贴标签
1. 在碰中例旁写“已有：中刻子，副露可用，一翻”。
2. 在三色例旁分别写“3万：三色成立”“6万：三色消失”，保留两种结构等待。
3. 另开宝牌栏，不放入役保证栏。现在可以看出资格、分支与加值分别来自哪里。
:::
