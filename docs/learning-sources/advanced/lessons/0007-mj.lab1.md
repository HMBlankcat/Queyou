## 要做出的材料

交付原册5项与深化补充5项的原答、计算依据和订正。纸笔或Markdown均可，无须编程。每次先独立做一小段，再按自查清单核对；深化内容可拆为每段约5至8分钟，这不是对你的时间要求。

[原任务单](../lab/0007-基础篇/任务单.md)与[原作答页](../lab/0007-基础篇/作答/牌例册.md)继续使用；新增内容请打开[深化任务单](../lab/0007-基础篇/深化补充/任务单.md)和[深化作答页](../lab/0007-基础篇/深化补充/作答/深化册.md)。两份作答分别保留，便于回看最初依据。

## 本轮新增的动作

1. 牌数状态与延单骑的合法性：先把固定面子画在暗牌之外；延单骑每条完成都要确定雀头。振听的不同来源不要互相覆盖。
2. 固定符、荣和明刻与逐家账目：先问是不是固定符；普通形再看最后一张到底补成明刻还是暗刻。桌面供托不能再次向某位对手扣除。
3. 进张按实体去重并检查役分支：同一枚2p从甲河移入乙副露，只占一个实体。先枚举四种进张，再一行一行扣数。
4. 特殊形与孤张覆盖的两种比较：标准形之外单独数不同对子；局部功能比较先确认手中资源是否真的可用。
5. 安全矩阵与第四枚字牌的反例：先写谁自己舍过什么，再考虑筋能排除哪条两面。字牌数量要保留特殊形反例。

## 怎样算核心点齐全

本实验仍按前置节点目标核对：完整等待与三种振听、门前和副露役路线、计符例外与逐家支付、向听和进张去重、安全对象与规则边界。每条都要有具体原答与理由，不能只填最后一个牌名。

| 核对项目 | 应留下的可观察记录 |
| --- | --- |
| 牌数状态与延单骑的合法性 | A1/A2计数、全部等待、合法役、舍牌振听整组限制、临时解除与立直后持续限制均须有独立依据。 |
| 固定符、荣和明刻与逐家账目 | 固定20与25符正确；普通荣和/自摸的明暗刻、翻数和符同时更新；每笔支付独立进位；本场供托账目完整。 |
| 进张按实体去重并检查役分支 | 完整进张并集、去重实体数、未见上限与每条役路线均对应同一舍后状态。 |
| 特殊形与孤张覆盖的两种比较 | 不漏七对子；四枚同牌不能算两种对子；自由暗牌与固定副露有别，不能将局部结论升级成全手最优。 |
| 安全矩阵与第四枚字牌的反例 | 对象和时点齐全；筋不是保证；拟舍第四枚字牌仍检查国士，额外条件必须针对国士所需幺九。 |

合理的替代拆分或策略可以保留：牌数、规则与算术正确，取舍和前提明确，未知信息仍标未知。不能在未给牌河、概率或平台制度时补造确定结论。

## 分步开始

1. 先在原册保留已有作答，再到深化册抄清一个任务的已知条件。
2. 逐步画拆分、列实体或写逐家账；完成后立即用该任务自查项找缺项。
3. 将原答与订正分栏，整段完成后再从练习册说明打开独立答案。
4. 若要做延迟复查，另一天用新例独立执行同一个动作，写真实日期与结果。

## 自查与常见卡点

- 枚数不合时，先把公开面子、暗杠与隐藏牌分开，不添第五枚同种牌。
- 等待或进张不同，恢复原手逐牌种再试，不能混用两种备选拆分。
- 点数不同，先查役与符，再查庄闲、本场、已有供托及自己的新供托基准。
- 安全或策略说不清，先写对象、时点、已知事实和合法反例，再补比较理由。

## 材料检查的边界

维护者可选的字段检查只读取少量固定数值和留白，不能判断开放理由、唯一最优或掌握。学生无需安装运行环境；纸笔按清单即可即时找缺项。
