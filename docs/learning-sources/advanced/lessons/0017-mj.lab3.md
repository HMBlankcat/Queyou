## 要做出的材料

交付原册4项与深化补充4项的原答、计算依据和订正。纸笔或Markdown均可，无须编程。每次先独立做一小段，再按自查清单核对；深化内容可拆为每段约5至8分钟，这不是对你的时间要求。

[原任务单](../lab/0017-高手篇/任务单.md)与[原作答页](../lab/0017-高手篇/作答/牌例册.md)继续使用；新增内容请打开[深化任务单](../lab/0017-高手篇/深化补充/任务单.md)和[深化作答页](../lab/0017-高手篇/深化补充/作答/深化册.md)。两份作答分别保留，便于回看最初依据。

## 本轮新增的动作

1. 完整结局表与条件变化：先检查每组概率之和，再按同一收支口径加权。增加保证打点和增加平均每局收益不同。
2. 四家账目、必要得点与自己的供托：每条路线恢复原点数。四家现金与桌面池合计先后均为100000；自己的新棒先付后取回，不能凭空增加收益。
3. 候选暗牌的数量更新与价值分支：数量信息可排除持两枚的候选，未必排除持一枚的单骑。公开一翻和实际只值一翻不是一回事。
4. 四格复盘、抽样与另日新例：有根据却没和、错误理由却通过都可能发生；统计要用相同机会定义。新例的实际执行留给学生，参考解不是已发生证据。

## 怎样算核心点齐全

本实验仍按前置节点目标核对：完整结果分支与敏感性、四家账目和必要得点、读牌候选与价值范围、理由结果四格和延迟新例。每条都要有具体原答与理由，不能只填最后一个牌名。

| 核对项目 | 应留下的可观察记录 |
| --- | --- |
| 完整结局表与条件变化 | 覆盖全部结局、算术和口径正确；模型假设与真实局况分开，说明防守也可能失点及后续风险。 |
| 四家账目、必要得点与自己的供托 | 必要得点、三种支付、自己供托基准、流局分组和终局规则完整；逐家守恒后再排目标关系。 |
| 候选暗牌的数量更新与价值分支 | 每个反例四张且与公开面相容；数量排除准确；役分支正确，推断不越过证据边界。 |
| 四格复盘、抽样与另日新例 | 等待与计数正确；四格独立于输赢；比例有分母；新例计划可执行且日期、原答不由备课人填写。 |

合理的替代拆分或策略可以保留：牌数、规则与算术正确，取舍和前提明确，未知信息仍标未知。不能在未给牌河、概率或平台制度时补造确定结论。

## 分步开始

1. 先在原册保留已有作答，再到深化册抄清一个任务的已知条件。
2. 逐步画拆分、列实体或写逐家账；完成后立即用该任务自查项找缺项。
3. 将原答与订正分栏，整段完成后再从练习册说明打开独立答案。
4. 若要做延迟复查，另一天用新例独立执行同一个动作，写真实日期与结果。

## 自查与常见卡点

- 枚数不合时，先把公开面子、暗杠与隐藏牌分开，不添第五枚同种牌。
- 等待或进张不同，恢复原手逐牌种再试，不能混用两种备选拆分。
- 点数不同，先查役与符，再查庄闲、本场、已有供托及自己的新供托基准。
- 安全或策略说不清，先写对象、时点、已知事实和合法反例，再补比较理由。

[深化自查清单](../lab/0017-高手篇/深化补充/自查清单.md)逐项列出了要求。卡住依次核对条件、回看带解例、索取提示、索取线索，完成后才对照答案。

## 材料检查的边界

维护者可选的字段检查只读取少量固定数值和留白，不能判断开放理由、唯一最优或掌握。学生无需安装运行环境；纸笔按清单即可即时找缺项。

本页是出题与任务说明，尚未发生学生验收。正式验收须覆盖全部必需核心点，逐条引用学生真实原答、解释与隔开时间的新例证据；同日重试、看过课件和备课参考运行均不能单独替代。
