## 要做出的材料

交付原册4项与深化补充4项的原答、计算依据和订正。纸笔或Markdown均可，无须编程。每次先独立做一小段，再按自查清单核对；深化内容可拆为每段约5至8分钟，这不是对你的时间要求。

[原任务单](../lab/0012-进阶篇/任务单.md)与[原作答页](../lab/0012-进阶篇/作答/牌例册.md)继续使用；新增内容请打开[深化任务单](../lab/0012-进阶篇/深化补充/任务单.md)和[深化作答页](../lab/0012-进阶篇/深化补充/作答/深化册.md)。两份作答分别保留，便于回看最初依据。

## 本轮新增的动作

1. 完全一向听和计划外的新分支：每条分支先恢复原手；一对进成刻后，谁接替雀头？旧拆块计划需要随新牌更新。
2. 解决急所与后付路线的保证：两条都到听还不够，写出剩下的薄弱块。役牌暗刻并不因吃了另一组就统一变成明刻。
3. 无役默听与立直棒的两种基准：无役门前不等于可荣和。排名题从宣告前或宣告后记账均可，但自己的棒不能当作额外利润。
4. 三家威胁下的库存和首次风险：共同安全要逐列求交集。第一枚没通过前，不能预支第二枚的收益。

## 怎样算核心点齐全

本实验仍按前置节点目标核对：完全一向听与六块重拆、急所与鸣后役保证、立直默听的资格和得点、连续防守与首次通过的条件。每条都要有具体原答与理由，不能只填最后一个牌名。

| 核对项目 | 应留下的可观察记录 |
| --- | --- |
| 完全一向听和计划外的新分支 | 六种进张无重复，残枚实体扣除正确；两个分支保持合法13张；新两面和重叠牌更新清楚。 |
| 解决急所与后付路线的保证 | 鸣后实物、等待和30符一翻正确；比较最终等待而非只看降向听；后付许可和最终成役分开。 |
| 无役默听与立直棒的两种基准 | 普通荣和资格清楚；两个等待的确定翻数分别算；本场、自己供托、终局与未来风险各有记录。 |
| 三家威胁下的库存和首次风险 | 新增对象和已耗资源都更新；1p新增乙依据且对丙有依据；8m筋不能升级成现物，后续收益保留条件。 |

合理的替代拆分或策略可以保留：牌数、规则与算术正确，取舍和前提明确，未知信息仍标未知。不能在未给牌河、概率或平台制度时补造确定结论。

## 分步开始

1. 先在原册保留已有作答，再到深化册抄清一个任务的已知条件。
2. 逐步画拆分、列实体或写逐家账；完成后立即用该任务自查项找缺项。
3. 将原答与订正分栏，整段完成后再从练习册说明打开独立答案。
4. 若要做延迟复查，另一天用新例独立执行同一个动作，写真实日期与结果。

## 自查与常见卡点

- 枚数不合时，先把公开面子、暗杠与隐藏牌分开，不添第五枚同种牌。
- 等待或进张不同，恢复原手逐牌种再试，不能混用两种备选拆分。
- 点数不同，先查役与符，再查庄闲、本场、已有供托及自己的新供托基准。
- 安全或策略说不清，先写对象、时点、已知事实和合法反例，再补比较理由。

[深化自查清单](../lab/0012-进阶篇/深化补充/自查清单.md)逐项列出了要求。卡住依次核对条件、回看带解例、索取提示、索取线索，完成后才对照答案。

## 材料检查的边界

维护者可选的字段检查只读取少量固定数值和留白，不能判断开放理由、唯一最优或掌握。学生无需安装运行环境；纸笔按清单即可即时找缺项。
