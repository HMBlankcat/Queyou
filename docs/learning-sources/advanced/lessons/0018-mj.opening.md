## 计划要说明后续

前面的牌效率课比较一次舍牌后的向听与受入。本章把观察范围延伸到接下来的几次行动：当前留下的牌准备做什么；哪些牌只有在其他材料补齐后才会舍；出现什么信息，原来的安排就需要改变。

**补块**是把孤张或不完整材料发展为一个可用的面子、搭子或对子。**候补块**是尚未完成、准备用来承担某个结构职责的材料；它可能只有一张孤张，也可能已有搭子。候补不等于完成，更不能把同一张牌同时算入两个计划中的块。

一份序盘计划至少应说明三件事：目前缺少的结构职责、暂定保留的路线，以及会触发改判的新信息。它可以很短，例如：“已有两面子和一个两面；先让5索补第四个面子材料，字牌暂时保留补雀头与役牌的机会；一旦雀头和第四块都有着落，就处理多余字牌。”这比单独记住“先打西”包含更多可以核验的内容。

计划中的“先、后”都有条件。准备舍9筒，并不表示下一摸即使得到8筒也仍须舍9筒；准备保留中，也不表示面对立直还要为一个未成立的役牌路线继续打危险牌。

## 从配牌分配用途

设东一局，自家南家，门前，无赤牌，宝牌为8万，本例手牌中没有宝牌。未列出的他家手牌与未来摸牌均未知。最初十三张为：

`23m56p789s5s9p东中西北`

第一摸得到4万，摸后十四张为：

`234m56p789s5s9p东中西北`

先按用途看材料，再决定舍牌。

| 当前材料 | 已经具有的用途 | 仍需补足的条件 |
| --- | --- | --- |
| 234万、789索 | 两个完整面子 | 可暂时保留，后续仍允许整手重拆 |
| 56筒 | 第三个面子的两面材料 | 摸4、7筒可完成 |
| 5索 | 补出另一块的候选 | 摸邻张成搭子，或重叠成对子 |
| 9筒 | 另一条补块候选 | 靠7、8筒发展，当前只有孤张 |
| 东、中 | 雀头候选，也可能发展役牌刻子 | 需再得到同牌；对子本身没有役牌这一役 |
| 西、北 | 非役牌的雀头候选 | 同样需要重叠；当前没有安全保证 |

在这一拆分下，目前只有两面子和56筒这三块已经成形，雀头也没有确定。5索承担的独立补块用途较清楚；如果立即舍掉所有字牌，日后还要从数牌里另外形成雀头。

本例采用的示范选择是先舍西，保留东、中一段时间，北作为另一项雀头候选。这个选择的依据是手牌仍缺材料，字牌尚有可能实际进入最终结构。它不要求读者把西和北在所有局面下排成固定次序，也没有证明这手牌存在唯一最优第一打。

“保留役牌路线”还需区分两层：保留一张东只是保留发展机会；直到东形成刻子，才取得场风役。若未来东只作雀头，它提供结构，却不能提供这个役。

## 写出暂定舍牌次序

舍西后，十三张为：

`234m56p789s5s9p东中北`

可以把后续安排写成有条件的三步。

1. 若5索靠成有用的新块，优先比较9筒与多余字牌，减少重复的补块材料。
2. 若东、中或北先成为雀头，就重新检查其他孤张；不再把每张字牌都当作必需的雀头候选。
3. 若普通五块已经齐全，而役牌刻子仍没有形成，就比较门前推进与继续等待役牌的代价。

这里没有承诺“下一打一定9筒”。例如下一摸8筒，9筒立即变为89筒边张；原先“9筒只有孤张用途”的理由已经改变。是否留下89筒，还要与5索、字牌候选及最终五块比较。计划的用途是提示需要复核哪项职责。

若在配牌时就写死东、中、北一定全部舍去，也会漏掉这个例子的特点。当前没有雀头，其中一张重叠后可能正好解决缺口。暂时保留它，与在五块已经整齐的手里保留一张没有用途的字牌，支付的是不同的牌位成本。

## 连续追踪四次摸舍

下面是一条为教学选定的后续分支。各次摸牌都只是条件示例，并非对未来的预测；每行列出的都是舍牌完成后的十三张。

| 新摸牌与舍牌 | 完整十三张 | 结构更新 |
| --- | --- | --- |
| 已摸4万，舍西 | `234m56p789s5s9p东中北` | 普通形3向听；仍缺第四块与雀头 |
| 摸6索，舍9筒 | `234m56p56789s东中北` | 普通形2向听；索子可按56、789分为两块 |
| 摸东，舍北 | `234m56p56789s东东中` | 普通形1向听；东东补上雀头，四面子材料已有着落 |
| 摸4筒，舍中 | `234m456p56789s东东` | 听牌；等待4、7索 |

第二行不能把56789索看成“已经有两个面子”。它只有五张，可以暂按56索搭子与789索面子分配，仍少一张。第三行得到雀头后，中不再承担必需的补头职责；第四行56筒完成，舍中即可把剩余索子固定为最终等待。

最终加入4索时，索子拆为456、789；加入7索时，拆为567、789。完整等待是4、7索。只扣最终手牌且无额外已见牌时，4索有4枚，7索因手中已有一枚剩3枚，共7枚可见上限。这个数字没有说明七枚都在牌山。

这一分支最终仍然没有役牌刻子。东东是场风雀头，使平和不成立；手中含789索，也不成立断幺。普通荣和还需另有合法役，例如在满足条件时选择立直。序盘留下东的方案解决了雀头，最终并没有兑现所有曾经保留的价值可能。

## 役牌成刻后的转向

回到第三行：

`234m56p56789s东东中`

若下一摸为第三枚东，舍中后得到：

`234m56p56789s东东东`

这手普通形仍为1向听，并未因东成刻便自动听牌。原来的东东由雀头转成面子，整手又需要安排雀头。与此同时，东刻子已经提供场风役，副露推进的合法役条件也与前一状态不同。

这个变化说明，同向听并不等于原计划原封不动。原计划中的“东负责雀头”需要撤回，替换为“东提供面子和役，其他数牌补雀头”。56筒与索子复合材料的重叠牌，现在也可能具有补头用途。

这里的**路线转向**，指的是随着材料和目标变化，重新分配最终结构与役的职责。它可以只涉及雀头和一个面子的调换，也可以涉及从门前路线转为有役副露；不必每次都把整手牌推倒重来。

再看另一种公开信息变化。在第二行`234m56p56789s东中北`时，若牌河中已出现另外两枚东，手中这一张东最多只能再重叠一次，不能靠剩余牌形成东刻子。这时东仍能补雀头，却已经失去本例所期待的场风刻子分支。中若尚未出现，则它的役牌候选用途与东不同。比较时应改写用途，不能只沿用“东的役比中更重要”的旧标签。

## 整齐手的字牌安排

保持东一局、自家南家、无赤与宝牌8万的题设，另看摸后十四张：

`23m56p67s55m789p东中西`

当前可选的五块为23万、56筒、67索、55万和789筒。四面子材料与雀头都已安排，东、中、西在这份门前普通形计划里都属多余牌。与前一例相比，字牌重叠已经不再解决一个尚未填补的必需职责。

如果自家准备沿这五块推进，并且当前没有必须保留某张字牌的点况理由，就可以安排先处理东、中，随后处理西。其考虑包括：东为场风，东家持有对子时可能鸣成双东；中可能成为任何一家的役牌；西在本题设下不是场风或自风。不过，这只是结合“几张牌终将舍出”的行动安排，不能证明某张牌当前一定无人能鸣，或一定不会被荣和。

换成散手时，保留东、中可能是为了它们重叠后进入最终结构；换成这里的整齐手，继续扣住它们则需要支付占用牌位的成本。两种处理的差异，来自自己对这些牌的实际用途。

还有一个需要重新检查的条件：如果目标点差要求提高打点，而现有路线缺少增值机会，某张役牌便可能重新成为候选。此时应同时写清为此拆掉哪一块、增加多少推进要求。仅写“需要高打点，所以留役牌”仍然不够完整。

## 让计划接受新信息

序盘计划可沿用既有练习册的记录方式，写成“手牌—公开信息—候选—理由—更新”。更新时特别检查以下对应关系。

| 新信息 | 需要重新核对的内容 |
| --- | --- |
| 孤张摸成搭子或对子 | 是否补上原先缺少的块或雀头；其他候选是否变多余 |
| 役牌同种牌继续出现 | 役牌刻子还可能形成吗；保留为雀头是否仍有用途 |
| 摸到宝牌或赤牌 | 原路线已经有多少价值；为新增价值要改动什么结构 |
| 他家出现明显威胁 | 原定后续舍牌是否还能承受；手中可用安全牌剩多少 |
| 点况或本局目标改变 | 当前计划追求速度、打点与风险的比重是否应调整 |

安全性要在实际舍出的那一刻重查。某张牌原本预定在序盘处理，并不因此在中盘仍然安全；保留一张字牌作后续防守候选，也不等于它已经成为任何人的现物。

## 来源与适用范围

本章采用小林刚《超级数据流麻将》手顺1—3节已取得的中文文字中关于“终将舍出”与“尚将保留”的条件比较，并结合 Riichi Book I 关于补块与可实现手役的讨论展开。以上牌例均为自主构造；没有还原未读取的中文原牌图。

这里的暂定次序是带前提的教学方案，未使用雀魂段位统计，也没有将先舍役牌或保留字牌规定为普遍最优策略。
