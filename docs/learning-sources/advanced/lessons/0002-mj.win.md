## 每张只用一次

**顺子**是同花色连续三张数牌，如`234m`；**刻子**是三张相同牌，如`白白白`。它们统称**面子**。标准和牌需要四个面子与一个**雀头**，雀头是一对相同牌。

```text
123m | 456m | 789p | 中中中 | 55s
顺子   顺子   顺子    刻子    雀头
 3  +   3  +   3  +    3   +   2  = 14张
```

先数实物牌，再拆结构。`891m`不能绕回1，`东南西`不能组成顺子，`2m3p4s`也不能跨花色组合。相同牌最多四枚。不能用一枚3万同时画进`123m`与`345m`，若两组都需3万，原手中必须真实持有两枚。

某个拆分失败，不等于整手失败。可以先尝试某种雀头，从余牌取刻子或顺子；若余牌无法分完，就还原原牌，再换雀头或面子。还原是必要动作，不能把前一种拆分已经耗用的牌带进后一种。

例如`11223344556677m`既能按七对子理解，也能拆为`123m、123m、456m、456m、77m`。不同拆分的役与符未必相同，计分时应选完整、合法且得点最高的一种解释，不把两种解释的条件混加。

## 两种特殊结构

**七对子**是七种不同牌各两枚，并且保持门前，例如`11m44m22p88p33s东东白白`。这里有七种牌、十四枚牌；四枚相同牌不能算成两种对子。七对子本身提供役，普通四面子计算方法不适用于它。

**国士无双**需要十三种幺九牌`19m19p19s东南西北白发中`，另加其中任一种一枚作对子，并保持门前。

| 国士的13张状态 | 差哪一项 | 结构等待 |
| --- | --- | --- |
| 十三种幺九各一枚 | 缺对子 | 任意一种幺九，共十三种 |
| 十二种幺九，其中一种已有对子 | 缺第十三种 | 只等缺的那一种 |

例如`11m9m19p19s东南西北白发`缺中，已有一万对子，只等中。加中后是十三种加一对；加一万不会补上缺的中，不能因为“又多了一张幺九”就当作有效完成。

本课讨论的是三种手牌结构。流局满贯等是特殊结算，不应再硬拆成另一种普通十四张手牌。

## 门前与公开面子

**门前**是尚未吃、碰、明杠的状态，暗杠通常保留门前。吃只能使用上家刚舍的一张，配自己的两张成顺子；碰可使用任一家刚舍的一张，配自己两张同牌成刻子。吃、碰后直接舍一张，不再额外摸一张。

| 动作 | 组成方法 | 动作后的结构性质 |
| --- | --- | --- |
| 吃 | 一张他家舍牌加自己两张连续数牌 | 一组固定公开顺子，失去门前 |
| 碰 | 一张他家舍牌加自己两张同牌 | 一组固定公开刻子，失去门前 |
| 大明杠 | 一张他家舍牌加自己三张同牌 | 一组公开杠子，失去门前 |
| 加杠 | 给自己已碰出的刻子加第四张 | 公开刻子升为杠子，可涉及抢杠 |
| 暗杠 | 自己四张同牌按规则宣告 | 一组杠子，通常仍门前 |

**杠子**四张同牌按一个面子计，多出一枚实物牌。杠后从规定补牌位置摸入的牌叫**岭上牌**。不能只把四张牌移出去便认为手牌完整；补牌与随后的和牌或舍牌共同保持计数。

一个公开普通面子后，舍牌完毕通常是隐藏10张加公开3张；两个普通副露后是隐藏7张加公开6张。若已有k组杠，舍牌后的实物总数通常是13+k，完整和牌是14+k；面子数仍为四，杠没有让自己获得第五个面子。

暗杠也应作为固定面子记录。立直后能否暗杠、加杠的响应、吃后可舍哪张等细项应由现行规则决定，不能从牌数正确进一步推出所有动作都被允许。

## 先找完整等待

**听牌**是十三张状态再补一种牌即可形成完整结构。能补全结构的牌构成**完整等待集合**。它描述结构；实际能否荣和还需检查役与振听。

| 基本等待 | 局部形状 | 等待牌 | 最后一张的作用 |
| --- | --- | --- | --- |
| 两面 | `23m` | 1、4万 | 补成顺子 |
| 嵌张 | `35p` | 4筒 | 补顺子中间 |
| 边张 | `12s`或`89s` | 3索或7索 | 补端头顺子 |
| 双碰 | `55m、白白` | 5万、白 | 一对成刻，另一对留作雀头 |
| 单骑 | 四面子外余`东` | 东 | 补雀头 |

完整例`23m456p678s中中中55p`有三个面子、雀头和`23m`，等待1、4万。局部表便于识别常见形，复合牌形则要重新拆整手。

看`1234m456p678s中中中`：摸1万，可拆`11m、234m`；摸4万，可拆`123m、44m`。因此等待1、4万，两个分支都是补雀头，不能因为牌种相同就叫两面。复合形课会继续比较这两种完成方式的价值。

人工枚举的可靠步骤是：保存原来的十三张；对每一种可能牌各加一枚；检查是否能完整分为标准形或合法特殊形；成功便记该牌种，随后撤回新增牌再试下一种。同一种牌有多个成功拆分，等待集合仍只记一次。已经持有四枚的牌不能再假设摸第五枚。

## 展开一次完整枚举

为了看清为什么整手重拆必要，考虑十三张`2223334m456p白白白`。筒顺与白刻先各占一个面子；其余七张万子在补一张后，需提供两个面子和一个雀头。若只把222和333各圈成刻子，视野里只剩4万单张，很容易只记住4万。

先保持原牌不动，再逐种加入候选。下面每行都把新增牌撤回后才进入下一行，表内拆分只是对应完成牌的一种合法解释。

| 新增牌 | 八张万子的拆分 | 加上固定两面子后的结果 |
| --- | --- | --- |
| 2万 | 222、234、33 | 四面子加33雀头 |
| 3万 | 234、333、22 | 四面子加22雀头 |
| 4万 | 222、333、44 | 四面子加44雀头 |
| 5万 | 222、345、33 | 四面子加33雀头 |

因此完整结构等待为2、3、4、5万四种。2万原有三枚，3万原有三枚，4万原有一枚，5万没有；只扣手牌时，各自还可能有1、1、3、4枚，共9枚上限。“四种等待”不等于十六枚，也不说明四种牌在牌山中同样容易出现。

试加1万则需要重新从`12223334m`分完八张，不能借用上一行已经成功的雀头。逐一试尽34种牌，是检查“没有其他等待”的办法；只展示四个成功拆分，单凭展示本身还没有证明其他30种都失败。人工记录可先列成功者，再用整手复查补漏。

## 拆分与固定的区别

未副露的完成面子可以重新分配。例如上例初看有222暗刻和333暗刻，但摸入2万的完成解释把一枚2万和一枚3万拨给234，留下33作雀头。实物没有增加，改变的只是职责。

公开碰出的222则不同。那三枚2万已经作为固定面子，不能拿其中一枚去拼234，也不能把公开刻子退回对子。若一张牌谱画着固定副露，枚举时须先保留它，再处理剩余暗牌。把整副14张完全打散计算，可能得到规则上不能执行的拆分。

| 记录对象 | 能否重拆 | 检查方法 |
| --- | --- | --- |
| 暗牌中暂划出的222 | 通常可以 | 每个完成分支重新分配实物 |
| 已碰出的222 | 不可拆回暗牌 | 作为一组固定面子计数 |
| 已宣告的暗杠 | 作为固定杠子 | 不因保留门前就恢复拆分自由 |
| 七对子解释 | 按七种对子计算 | 不把其中三张又拿去组成刻子 |

“保持门前”与“每一张都能自由重拆”因此不是同一件事。暗杠虽然保留门前，组成杠子的牌仍已固定。这个区别以后会影响立直、役和改良，但本课先把合法结构保存正确。

## 合法性逐项失效

对同一个等待集合，可以逐项改变条件以找到阻断位置。以上例为基础，枚数、结构与限制应各留一行，不能只用一句“不能和”结束。

| 当前变化 | 哪一层要改 | 哪一层仍保留 |
| --- | --- | --- |
| 自己此前舍过4万 | 荣和资格受舍牌振听限制，四种都不能荣和 | 2、3、4、5万仍是结构等待 |
| 其他区域又见一枚2万 | 2万未见上限从1变0 | 不据此抹去与舍牌历史的结构检查 |
| 来牌是自己摸入的3万 | 改按自摸方式检查，振听不直接禁止自摸 | 仍须确认结构、役与取得方式 |
| 把某个固定副露误拆成暗牌 | 先修正拆分是否合法 | 不能靠后面算出有役挽救非法结构 |

一层检查通过，只能说明这一层没有阻断。反过来，一层已经失败，也应保留其他层的真实结果：这样订正时才知道要修哪一步，而不会把原本正确的等待或枚数一起改错。

## 有形还要有役

**役**是规则规定的和牌资格条件，例如役牌刻子、门前清自摸和、立直等。**宝牌**只在合法和牌之后加值，本身不构成役。完整结构、至少一个可用役、和牌方式与限制三项都必须成立。

将完整例的中刻子换成普通条件下无役牌价值的西刻子，得到`23m456p678s西西西55p`。假设门前未立直、无其他过程役，结构仍等1、4万，但普通荣和没有役；合法自摸时则可以取得门前清自摸和。若西刻子早已碰出，门前清自摸路线也消失，还须另找役。

这个对照解释了“结构听牌”和“现在能荣和”的差别。不能删掉不能荣和的一侧等待来伪造另一种结构等待；下一项振听仍以完整结构等待为基础。

## 舍牌振听看全组

**振听**是禁止荣和的状态。只要其他条件合法，振听仍可以自摸。最常见的**舍牌振听**发生于当前完整结构等待与自己本局舍牌有交集；这时整组等待均不能荣和。

自己等1、4万，此前舍过1万，别人现在舍4万也不能荣和。证明可以分两步：当前等待中包含自己舍过的1万；因此整手处于舍牌振听，限制同时作用于4万。

自己舍出的1万即使后来被别人吃碰，仍属于自己本局舍牌记录。牌河画面上的空位、横放牌和客户端提示只是呈现，规则判断要保存真实历史。另一方面，过去舍过1万并不永久禁止本局所有荣和；改变手牌后若新的完整等待不含任何自己舍牌，就需要按新状态重查。

| 改变条件 | 应怎样重查 |
| --- | --- |
| 仍等1、4万，1万已舍 | 整组受舍牌振听限制 |
| 通过合法换形改等2、5万 | 与自己全部舍牌重新求交集 |
| 1万已公开四枚 | 它仍属于结构检查涉及的牌种，不能据此忽略舍牌振听 |
| 某一侧完成形没有役 | 不能擅自删去该结构等待再判振听 |

最后两行提醒：物理残枚、合法役与舍牌历史是不同检查。对“无役侧等待”如何触发临时振听等细节，须依本课采用的通用规则与实际房间复核，避免只看客户端是否亮荣和按钮。

## 见逃与解除时点

**见逃**是在他家出现等待牌时选择不荣和。非立直状态下的**同巡振听**，在普通无鸣牌插入的摸打中，到自己下一次摸牌的轮次后解除；但若同时有舍牌振听，后者仍持续。立直后见逃则本局持续振听，下一次摸牌不能解除。

| 当前状态 | 放过等待牌后 | 下一次普通摸牌后 |
| --- | --- | --- |
| 未立直，且无舍牌振听 | 临时禁止所有荣和 | 临时限制解除，重新查全套条件 |
| 未立直，另有舍牌振听 | 两项限制可同时存在 | 临时限制解除也不自动消除舍牌振听 |
| 立直后见逃 | 本局持续禁止荣和 | 仍不能荣和；合法自摸另查 |

例如下家舍4万，自己放过；对家紧接着又舍1万，在自己下一次正常摸牌以前，不能改口荣和1万。若无其他振听，轮到自己正常摸牌后再遇来牌，才重新按当前状态判断。吃、碰、杠插入会改变轮转，精确解除时点不能用“又有人打了一张”或“我喊过一次碰”代替规则。

这套时点区别也是现物防守的基础：别人已经受限制，自己才能在明确时窗内利用同种牌的安全性。安全课会逐家标注它能持续多久。

## 一条可复核的链

记录一次和牌判断时，按以下顺序写出可检查结果：枚数与公开面子；至少一种完整拆分；全部结构等待；对每个来牌的役与完成方式；自己舍牌交集和见逃状态。计数正确只通过第一步，不能代表后续已经完成。

::: practice 练习 | 跟做合法性记录
1. 抄写`23m456p678s中中中55p`，核对十三张，分别加入1、4万并画出四面子与雀头。
2. 标记中刻子提供役，然后补入“自己此前舍过1万”，写出“1、4万都不能荣和，合法自摸仍可”。
3. 将这条记录拆成“结构等待：1、4万”“役：中”“限制：舍牌振听”三行。结果应保留所有等待，且能指出究竟是哪项限制阻止荣和。
:::
