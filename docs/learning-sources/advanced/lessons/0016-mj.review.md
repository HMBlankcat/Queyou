## 冻结当时的信息

**牌谱**是按顺序记录摸牌、舍牌、鸣牌、和牌及局况的对局记录。复盘先停在一个可替换的决策点，隐藏未来摸牌和他家暗牌，再恢复当时自己能够看到的信息。雀魂牌谱与统计入口可能变化，操作以当前客户端为准。

复盘单位是一次选择：舍哪张、鸣不鸣、是否立直、维持进攻还是转守。整局输赢还混入其他选择与随机结果，不能直接代替这个动作的评价。实际理由记不清，应诚实标未知，之后重新构造的好理由不能冒充临场已经想过。

| 记录栏 | 要恢复的具体信息 |
| --- | --- |
| 定位 | 局号、本场、巡目、庄闲、四家点数及终局条件 |
| 当时已知 | 自手牌、明牌、指示牌、牌河与宣告 |
| 原动作与理由 | 实际舍牌或宣告，记得的理由与明确的未知 |
| 替代候选 | 至少一个当时合法动作及其舍后完整状态 |
| 比较依据 | 向听、完整等待与残枚、役和价值、风险与排名 |
| 假设边界 | 暗牌、概率、未核对规则和会影响结论的条件 |
| 后续观察 | 实际发生什么，与理由是否成立分栏 |
| 训练任务 | 一个能在新例中重复观察的动作与核对方法 |

**反事实候选**是同一信息点上原本可以采取的另一动作。它不能使用后来才摸来的牌；自己已立直后的候选也须受宣告约束。每条候选都要重算合法役、牌数与后续状态，不能换了动作却继续沿用原等待。

## 一次结果相反的比较

题设第六巡，无明显威胁，普通点差，无宝牌影响，14张为`55m778p234s678s白白白`，其他已知位置没有相关等待牌。比较舍一张7筒与舍8筒：

| 合法动作 | 舍后13张 | 完整等待与未见上限 |
| --- | --- | --- |
| 舍7筒 | `55m78p234s678s白白白` | 6、9筒，两面各四枚，共八枚 |
| 舍8筒 | `55m77p234s678s白白白` | 5万、7筒双碰，各两枚，共四枚 |

两条路线均有白役牌。在给定的普通条件下，两面路线有较充分的基本等待依据。若下一家后来恰好舍5万，双碰路线本次可能立刻和牌；这张后来出现的牌没有增加第六巡时的信息，不能单独推翻原比较。

“可能立刻和牌”还须尊重其他条件：当时若振听或该家舍牌前有别的结算，便不能直接照写。反事实用于比较可行方案，不应把未实际发生的整条未来路径都当成确定历史。

若原来6、9筒已有多枚可见，八枚上限应扣减；若7筒安全、8筒危险，安全依据额外支持舍7筒；若局末特定得点改变目标，则价值分支也要加入。每次修改都要指出改变的是哪项已知条件，不能看到结果后悄悄换题设。

## 理由与结果分两轴

**结果偏差**是让好结果替坏理由背书，或用坏结果直接否定有依据的选择。可用下面四格组织复盘；这是本课的记录方法，不是关于四类出现比例的统计结论。

| 当时理由的质量 | 本次结果有利 | 本次结果不利 |
| --- | --- | --- |
| 依据充分、条件适用 | 保留可迁移的依据，再查是否有遗漏 | 先查信息与计算，理由仍成立则接受波动 |
| 依据缺漏、条件不适用 | 修正理由，不能因赢了便略过错误 | 定位具体缺口，把它转成下一次动作 |

理由充分也不代表动作已被证明全局最优。若两条方案都合理、概率未知，就记录各自成立条件与未决项；不能为了填表强行把其中一个判成错误。相反，“我猜他没有”即使本次猜中，也没有自动获得可重复依据。

揭示暗牌后可以检验：当时是否漏记真实公开信息、某种暗牌是否结构可行、推断是否过强。不能把揭示后才能知道的等待写回原信息栏，再声称临场本应精确读中。

## 反事实不能照抄未来

只改一张舍牌，在部分情境下可能不改变下一张自摸，但它仍可能改变对手吃碰、立直与押引。改变一次鸣牌更可能改变行动顺序、各家摸到哪张及终局时间。因而“如果当时碰了，后来同样摸到这张就赢”往往用了未被保证的路径。

可以比较当时各动作留下的向听、进张、役保证、可执行防守与目标条件；若要比较后续，应展开条件分支，或使用能明示假设的分析工具。工具给出的具体未来也不能自动当作真实必然发展。

本轮已读的平泽元气牌谱研究文字支持按决策信息评价，并提醒不要仅以一局结果下结论。本课用冻结信息、候选表和四格将这一原则变成记录步骤；未核对的原牌图不作为本例依据。

## 错误分类要落到动作

| 缺口类型 | 可观察的错误 | 下一轮具体练习 |
| --- | --- | --- |
| 规则 | 漏无役、振听或鸣后牌数 | 对每个候选走牌数→结构→役→荣和资格检查 |
| 牌效 | 漏等待、重复计重叠受入 | 逐牌种枚举，合并集合，再按实体扣已见 |
| 价值 | 漏食下、符例外或自摸逐家取整 | 每侧完成分别计符翻，列庄闲支付 |
| 防守 | 现物对象错、只看当前一张 | 建对象矩阵，舍后更新库存和临时保证时点 |
| 押引 | 给进攻最好未来、给弃和零损失 | 同时列自和、放铳、他和、他摸与流局分支 |
| 排名 | 把个人收入当点差改善 | 对直击、旁家、自摸逐家记账并重排四名 |
| 信息 | 精确读牌过度、偷用未来暗牌 | 分事实与推断，给强结论找合法替代解释 |

一次选择可有多个缺口，每轮优先修一个能重复观察的动作。“多练防守”太宽，应改为“每次写出现物针对谁，并在新宣告后重建一列”。“别乱押”也太宽，应改为“1向听进攻先写到听时的第二次舍牌风险”。

订正应写出错误依据、适用条件与下一次操作，不能只把答案换成正确牌名。看过解析属于学习机会；能在新牌例中独立执行并说明边界，才提供更强的学习证据。

## 一份完整复盘示范

以下为自编示范记录，原动作和原理由都是例中设定，不是学生实际成绩。第七巡普通点差、无明显威胁，无宝牌影响，14张为`233m123p66p67s白白白9p`。原动作舍一枚3万，设定的原理由是“重复牌看起来多余”。先隐藏未来与他家暗牌。

| 复盘栏 | 此例填入的内容 |
| --- | --- |
| 原动作后的真实状态 | `23m123p66p67s白白白9p`，1向听 |
| 当时合法替代 | 舍9筒，保留`233m123p66p67s白白白`，同为1向听 |
| 原动作受入 | 1、4万和5、8索，共16枚上限 |
| 替代动作受入 | 再多3万和6筒的成刻替代，共20枚上限 |
| 役与后续 | 白刻仍在；需逐分支写出到听后的雀头与等待 |
| 原理由缺口 | 没检查33对子能否替代66筒担任雀头 |
| 暂时结论 | 给定普通条件下，舍9筒有更充分的结构依据 |
| 可改变结论的信息 | 相关残枚耗尽、9筒舍出风险或末局价值条件不同 |

复盘到这里已经能定位一个可检查缺口，尚未依赖后来赢或输。即使揭示结果发现原动作之后本次和牌，遗漏的替代角色仍存在；即使替代动作在真实未来没有摸到进张，也没有因此从20枚变成零枚。

若实际牌河显示9筒对立直者危险，而3万安全，必须把这个真实事实补回风险栏再评价。此时原动作可能合理，但“重复牌就舍”的原理由仍不足；应区分动作可以被当时其他依据支持，与自己临场是否真的用了这些依据。

## 同一表错在不同环节

同样写错受入表，原因可能不同，对应训练不应全部叫“再练牌效”。如果知道摸6筒能成刻，却不知道把33万留雀头，缺的是职责替换；如果六种牌都列对却算成24枚，缺的是扣除手里已有的3万与6筒；如果20与16都算对却断言所有场合都必须舍9筒，缺的是条件边界。

| 可观察缺口 | 下一次应执行的动作 | 核对证据 |
| --- | --- | --- |
| 雀头替代漏掉 | 在每条成刻分支旁标出剩余雀头 | 新手牌确有一对且实物不重用 |
| 残枚扣错 | 原14张、已舍牌与公开牌按实体去重 | 每种进张的4减已知能逐项复算 |
| 忽略风险条件 | 对每候选补全威胁对象和安全依据 | 结论变化能指向一条新增事实 |

这张表定义的是操作证据。看过正确牌名后再抄同一答案，只能证明已经见过答案；若能在不同花色、不同已见牌或新威胁下独立改表，才开始证明方法在迁移。

## 分母不同会改解释

再看一组纯教学计数，不是平台数据或学生测验：某批牌谱共找出12个需要标注威胁对象的决策点，其中4个漏写对象；若只挑最终放铳的3个点，则其中2个漏写。

完整机会集合中的漏写比例是4／12，约三分之一；放铳子样本里是2／3，约三分之二。二者分子、分母都来自不同集合，不能把后者当成所有威胁决策的错误率，也不能据前者宣称漏写必然导致某个放铳概率。

若下一批只重复熟悉的例子，漏写减少也可能来自记忆题面。记录抽样方式、难度变化和是否首次遇见，才能判断前后是否可比。样本规模扩大能够减少部分偶然波动，却不会自动修复一直只挑惨败的选择方式。

复练的一个完整闭环，是先保留原记录，针对单个缺口重学相应推导，再用不同新例独立填写，核对实际错在哪个环节，隔开后再换例复查。最后更新的是“这个动作有了哪些新证据”，而不是根据几次正确替整门课或某段位作结论。

## 样本怎样选与统计

**选择偏差**是只复盘印象深刻的放铳或惨败，使样本偏向坏结果。可以每场固定抽取若干决策点，再补疑难标记；同时检查普通赢局、侥幸通过的危险舍牌、成功鸣牌与平淡舍牌。抽样方式与额外加入的理由都要记录。

统计必须带分母。和牌率应先确认按局、按场还是按机会计；某类决策的错误率应以真正出现该决策机会的次数为分母，不能只数发现了几次错误。不同客户端指标还须核对当前定义，不能凭名字假定相同。

比较前后还应记录东风或半庄、房间环境、样本量与训练内容。十次里错两次和五十次里错两次意义不同；对手、局制或选样方式变化，也可能改变数据。降低放铳率可能来自更好防守，也可能伴随过度弃和，应结合和牌机会与决策理由一起看。

短期排名与单个指标不能独立证明能力提高。过程证据可先看：完整等待是否漏枚、役保证是否分支、现物对象是否正确、点差计算是否守恒、新信息后是否重判。它们更贴近本轮正在练的具体动作。

## 让训练有复查闭环

一次复练可按“原缺口→对应课中带解例→少量新例独立执行→核对与解释→隔开后换新例复查”进行。若仍错，继续定位是规则没懂、枚举漏项、条件遗忘还是执行太快，再改训练动作。

保留每次实际作答与修改，不把教材完成、解析看懂或一次熟题答对直接记成掌握。材料交付只证明备课完成；学生证据须来自真实回答、操作与复测。
