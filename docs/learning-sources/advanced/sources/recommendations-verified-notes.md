# 推荐资料核对摘记（原创摘要）

> 本文件是本轮原创核对摘要，不是战术书或译文原文。核对日期：2026-11-01。未明确开放许可的完整网页抓取只在本轮 scratch 研究，不随正式学习目录归档。
> 证据层级：已读的新增材料是公开中文译文/转写，尚未与日语原书或原视频逐句比对。原著作者的判断与译者个人说明须分别处理。已知开放许可一手依据仍为 Riichi Book I 作者源稿。

## A. 小林刚：手顺与舍牌顺序

- 定位：[《超级数据流麻将》第一章手顺1—3节](https://www.bilibili.com/opus/382774984435256209)。作者小林刚；文内署翻译神仙酵母、校对射惠。
- 实际读取：译者说明、作者前言及“第一打W东”“如今的时代后付已是理所当然”“切19牌的顺序”的完整静态文字；页面含5个图片元素（其中封面有重复），牌图尚未读。不能称已核对全部图文内容，也不复刻其完整牌例。
- 原创核对结论：役牌价值取决于手牌速度、计划中的处理时机、是否可能形成役路线、他家鸣牌后果与点数局况。手牌较整齐且终究要舍的牌，与手牌散乱并可能长期保留的牌，应采用不同的判断。不能把“先舍役牌”或“扣住役牌”设为无条件规则。
- 原创核对结论：比较孤张时，要扣掉其他牌已经覆盖的受入。邻近4若仍是可用资源，与已经固定为完成面子的4，对孤张1的作用不同。备课时应用自编且枚数合法的牌形复算，不能仅从“1和4相邻”推出统一舍牌结论。
- 服务：mj.intro、mj.efficiency、mj.shapes、mj.calls、mj.defense、mj.placement；综合任务可服务 mj.lab1、mj.lab2、mj.lab3。
- 实施边界：前言中关于牌局独立的说法用于反玄学，不抹掉实际连续存在的点棒、本场、供托与排名状态；译者“适合避四网络环境”的评价也不是雀魂官方规则结论。

## B. 平泽元气：技能构成与训练优先级

- 定位：[初级讲座01《麻将水平高指的是什么》中文转写](https://www.bilibili.com/opus/439996743529922856)。文内署作者平澤元気，并列[原视频](https://youtu.be/XTvyerwqiuA)。
- 实际读取：完整静态文字（无图片）；原视频未观看、未核验音轨及字幕，不把中文转写当作已核对的日文逐字稿。
- 原创核对结论：可将训练分为进攻、防守与在两者之间作判断。初级训练先让学生能构造快速的合法和牌路线，再比较价值与防守，而读牌用于改进风险判断。现有课程把基础牌效、安全边界放在高级牌河推断之前，与这个训练优先级相符。
- 服务：mj.intro、mj.efficiency、mj.safety、mj.calls、mj.defense、mj.pushpull、mj.reading、mj.review。
- 实施边界：文中的“第一个1000点”是速度价值的对比讲解，不能扩展为任何点况都应无条件追求最快和牌；末局条件仍由明确的排名目标约束。

## C. 平泽元气：反结果论与复盘目标

- 定位：[《麻将、牌谱研究指南》第一章第5节《不要被结果论左右》](https://www.bilibili.com/opus/1018651004374089730)。文内给日文题名《麻雀・牌譜検討マニュアル》、作者平澤元気、出版社マイナビ出版。
- 实际读取：本节完整静态文字；2张牌图未读取。上传者声明部分内容机器翻译，且没有保证按顺序翻译整书，故不能称已读完整书或全章。
- 原创核对结论：复盘先固定决策时的公开信息，再比较可选动作；后来是否放铳、下一张摸牌、暗牌全开后的结果不替代当时依据。相同等待在普通中盘与末局大幅领先时，决策目标可能不同。可用“决策理由可靠/不可靠 × 当局结果好/坏”的四格记录训练，避免只在输牌后找错。
- 原创核对结论：应区分“能从当时信息评估的未见牌数量/范围”与“看了牌山后才知道的排列位置”。前者可以改变候选，后者不能回填为临场知识。
- 服务：mj.intro、mj.riichi、mj.pushpull、mj.placement、mj.reading、mj.review、mj.lab3。
- 实施边界：文字中的7成/3成只是作者为解释随机结果而设的假设，不是嵌张立直统计，更不是雀魂现行房间的放铳率。期望值的目标也要声明是点数还是排名效用，不能将局部点数均值直接当成整场排名最优。
