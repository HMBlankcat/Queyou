# 新专题技术来源核对摘记（原创）

核对日期：2026-11-02。本文件是原创技术摘要和定位，不是原著或译文原文。此次没有新增可读的网络正文；推荐帖里的《现代麻将技术论·手役构成理论》和《序盘的铁战略》入口均返回验证码页，已停止该站访问。阅读范围为此前实际取得的推荐译文及已公开的 Riichi Book I 作者源稿之下述段落。不得称为新读完推荐书或日文原著。

推荐中文译文提供序盘手顺的讨论方向，技术正文主要由 Daina Chiba 的 Riichi Book I 补足。该书面向初中级，其启发式不能直接升级为雀魂高手环境的统计阈值。作者 LaTeX 中牌形宏可辨认（wan/tong/suo 为万筒索，dong/nan/xi/bei 为东南西北，bai/fa/zhong 为白发中；rfw/rfd/rfs 为赤五，前缀 r 标鸣牌的横置），本轮实际读取源码里的牌形与相邻推导，未渲染书页。中文译文的原始牌图仍未读取，因此只取可独立成立的文字原则。

## A. 序盘计划：先选路线，再安排舍牌次序

定位：推荐《超级数据流麻将》手顺1—3节中文正文；Riichi Book I 第4章 Building a block（现有封装文件 L584–639），第5章开头 Pursuing yaku（L19–27）。

可独立教学的内容是配牌不整齐时如何给孤张分配未来职责：补面子、补雀头、保留役牌路线、后续安全候补；区分已接近完成且终究要切出的字牌，与散手中尚可能留下多巡的役牌。作者第4章用不足五块的手牌讨论补块，不止比较眼前受入；还展示为断幺、平和等可实现价值改变块配置。推荐译文明确反对把“总先打役牌”或“总扣住役牌”绝对化。

与旧牌效章的差别：新章组织一条“配牌判断→候选完成路线→未来两三步舍牌计划→摸牌后改计划”的连续流程；无需重讲向听定义或堆同类受入计算。

边界：不能引用未读牌图中的 A/B/C/D 手形；不把译者关于网络避四适用性的评价当平台规则；不保证某张危险牌越早打越安全，也不强迫散手预先锁死一役。

## B. 对子路线：七对子、对对和与普通面子手

定位：Riichi Book I 第5章 How to get toitoi / chiitoitsu（L597–700），分 Toitoi vs chiitoitsu 与 Standard hand vs chiitoitsu；第3章 Pairs / Pairs and sets（L279–387）作结构基础。

实际段落同时比较摸到第三枚同牌后保留刻子或继续七对，以及有五对子时转向含多两面的标准形。比较维度为三种路线各自的向听与进张、可见残枚、对子能否成刻、可兑现的役牌价值、鸣牌后失去七对与门前路线，以及中张对子可能难被打出的对手持牌因素。教材后者是策略解释，没有提供雀魂实测概率。

与旧牌形章的差别：把“同一手牌走哪条结构路线”作整章对象，连续演示路线保留、转向与关闭；不要简化为对对和役定义和七对计分重复。

边界：原稿说存在死对子时必须坚持七对，是其当前例子里的强表述，不能照抄成一般定理。单个死对子仍可作对对和雀头；应逐个检查剩余四刻子材料，多个死对子或需要其中之一成刻时才会产生具体结构阻塞。七对需七种对子，四枚同牌不算两个不同对子；标准向听更低或七对向听更低都不单独证明路线更快。原稿三对3—7中张的门槛不是已核验最优阈值。

## C. 染手：混一色的块数、增值与转向代价

定位：Riichi Book I 第5章 How to get honitsu（L472–596），包含 Conditions / Five-block potential / Hand value / Discard / Melding；第9章 Confirming yaku 的混一色分支（L180–193）。

源码明确以目标花色与字牌能否组成五块，以及染手和不染手两条路线的价值差来判断。可展开“同色牌很多却缺雀头/第五块”“有五块但只剩低值混一色”“原路线已有足够打点、染手损失两面速度”的反例。鸣牌次序还会保留或关闭役牌、一气通贯、混全带幺等价值分支；切掉外色好搭子的成本应明确列出。

与旧役章和鸣牌章的差别：沿同一目标花色持续管理块资源、外色退路与信息暴露，讨论为什么追染手、何时继续、何时退回普通形。

边界：第5章部分例子明确无赤五，不能移到含赤规则还沿用相同价值排序；5200之类是教材情境阈值，不能作总准则。隐蔽染手的舍牌顺序不能凌驾于役保证、实际残枚和对手威胁。清一色可作为结构与打点对照，不能宣称本轮另读过清一色专著或足够的清一色多面听专题。

## D. 宝牌与手役增值：为将来摸到的价值留接口

定位：Riichi Book I 第5章开头（L19–27）；第9章 When not to meld 2: big gap in hand values（L87–117）及 Be ready for dora（L426–448）。

原稿比较同一张被吃牌用两组自牌完成面子，两种吃法都听牌、当前价值相同，但只有一种仍可把未来另一枚宝牌收入手中并保持听牌。可独立讲“当前已保证价值、要靠后续摸牌才成立的价值、改变役或食下造成的价值损失”三栏；据此比较留宝牌、留宝牌靠张、门前价值与食下，不把加翻视作线性加点。

与旧计分章的差别：计分只是比较工具，主题是如何通过当前构筑保留未来加值分支；与旧鸣牌章相比，不再泛讲鸣不鸣，而是比较同一鸣牌的不同实施方式。

边界：宝牌不是役；未来里宝牌、一发、自摸不能当作必然收入。源稿关于牌的平均放铳价值只是情境化解释，不能变成“8一定比5安全”。本轮未新增任何概率统计或雀魂段位数据。

## E. 终盘形听：剩余机会与流局收支

定位：Riichi Book I 第7章无役默听例及脚注（L701–715，尤其 L711）；第8章 Miscellaneous / Turn 的开头（L382–384）；第10章未听罚符段（L245–246）。

可将最后数次摸打里“有役和牌、无役形听、弃和”的目标区分，先列仍有多少可实际行动的机会，再核对维持/取得听牌所需舍牌，以及流局时听牌/未听对逐家收支与排名的影响。第7章明确承认终盘无役默听为避免未听罚符有意义；第8章提醒来不及推进的一向听不能靠手牌潜力忽略当前风险。

与旧攻守章的差别：聚焦流局这一独立结算事件，区分结构听牌、可和牌、流局判听以及保听的机会成本。流局罚符3000点总额应明确设为教学题设，再逐家算1/2/3人听牌情形，推导同一对手间最大4000点的点差变化，不把4000误写为单家收入。

边界与证据深度：本专题技术正文比其他五项窄，适宜基础形听与账目章，不足以支持复杂“形听极意”固定押引阈值。原稿第10章“即使听牌也宣告不听从而结束比赛”的例子依赖人工宣告及终局规则，禁止写成雀魂可用操作。官方雀魂判听、连庄、终局仍未核验；教学题设必须写清，不自行断言平台允许任何特定形听/不听选择。不要引用未读的朝仓康心形听书。

## F. 副露推断：公开面子怎样限制役、价值与等待

定位：Riichi Book I 第8章 Defense against open hands（L414–589），包含 Guessing if an opponent has a ready hand、Estimating value、Identifying dangerous tiles 与 Discard upon chii 的三种情况。

公开顺子或刻子可排除部分役路线；役牌、宝牌、赤五提供已知加值，未见牌则留下其他值域。可先以公开面子筛选可行角色，再比较是否可能听牌、可能值多少，最后用“吃后舍同色/异色、碰后舍牌”的不同结构原因组织候选等待。原稿三例实际从鸣牌前的好形一向听推导而来，源码牌形及后续解释已实际读取。

与旧读牌章的差别：旧章讲一般可见信息、假设与反例；新章以公开副露为输入，逐步形成角色兼容表、已保证价值与未定价值、鸣牌前后牌形转换。须自主构造反例来演示外推限制。

边界：三副露、摸切、染手者开始舍本色等是警戒线索，均不逻辑蕴含听牌。吃后同色舍牌附近“安全”仅是建立在原稿好形一向听等前提下的相对推断，不是现物保证；对手可以从其他形、无役形或改良过程鸣牌。全碰也不能自动确定对对和，筋主要约束两面，不能因此称所有壁信息在任何刻子手里毫无作用。不能用卡顿、自动按钮或未核对的平台UI行为作暗牌证据。
