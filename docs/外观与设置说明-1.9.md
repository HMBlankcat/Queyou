# 雀友计点 1.9.0 · 外观与设置

作者：HMBlankcat。更新日期：2026-11-17。基于 1.8.0 升级。

## 安装与入口

直接安装 `Queyou-1.9.0.apk`，使用原包名 `com.queyou.score` 与原签名，versionCode 从 9 升为 10。覆盖安装可以保留原有对局、算点输入、学习和练习记录。打开 App，点击右上角「⚙ 设置」。

## 新增功能

| 设置 | 使用方式 |
| --- | --- |
| 主题 | 青竹、暖纸、夜墨、晴空、樱霞，或跟随系统自动切换明暗 |
| 背景 | 微光、竹影、暮色预设，自选纯色，以及从本机选择图片 |
| 自定义图片 | 支持常见 JPG、PNG、WebP，原图不超过 20 MB；自动缩小与压缩后保存在 App 本机存储中 |
| 图片布局 | 铺满背景或完整显示，位置可选顶部、居中、底部 |
| 背景不透明度 | 0–100%；数值越低，背景越淡 |
| 卡片不透明度 | 55–100%；数值越低，背景越容易透过卡片显示 |
| 背景模糊 | 0–16 px |
| App 亮度 | 默认跟随系统；关闭后可设为 20–100%，仅改变当前 App 窗口亮度，离开后恢复系统控制 |
| 牌面 | 默认使用参考图整理的雀魂风格，另有经典矢量、清晰大字；万、筒、索、字牌和三张赤五共 37 种完整收录 |
| 牌面辅助 | 紧凑、标准、大号手牌；可开启简短牌名标记 |
| 界面字号 | 100%、110%、120%；教材正文仍用阅读器内的字号控制 |
| 减少动效 | 关闭界面过渡与掷骰动画；系统减少动态效果偏好也会被尊重 |
| 常亮 | 使用 App 期间保持屏幕亮起 |
| 轻触反馈 | Android 上点击按钮时提供轻微振动，遵循设备的触觉反馈设置 |
| 启动页面 | 看牌算分、我的牌桌、学习书架或算点练习；下次启动时生效 |
| 外观方案 | 导出、导入包含设置与背景图片的 JSON 文件 |
| 重置 | 恢复本页默认设置并移除背景图片；对局、练习和学习记录保留 |

设置即改即存，关闭后再次打开仍然有效。牌面切换作用于算点、役种示例、练习、牌效及教材中以 App 牌面绘制的手牌。教材原书扫描页和原有配图保持原图。

## 数据与离线使用

外观偏好使用单独的 `queyou.appearance.v1` 记录；图片保存在独立 IndexedDB 中，不占用原有对局备份空间。导出的「对局备份」仍用于对局，外观另用「外观方案」导出。更换背景图片时会回收上一张图片。

「恢复默认外观」只重置外观。「牌谱 → 管理本地数据 → 清空全部本地数据」同时清除外观、图片和其他本地记录，操作前仍有确认。内置教材和功能不会被删除。

新增设置不需要联网、相册全盘访问、存储访问、修改系统亮度或振动权限。Android 使用系统文件选择器，只读取选择的文件。背景不会上传。浏览器预览中的亮度调节为页面明暗模拟，轻触反馈仅安装版可用；浏览器常亮依赖其 Wake Lock 支持。

牌面依据本次用户提供的参考图拆分整理；参考图牌纹的权利归原权利人。经典与大字牌面保留矢量绘制。应用为非官方线下麻将助手。

## 验证

通过原有 69 项规则、记账、练习、教材测试，以及新增 6 项外观存储、输入校验、写入失败回滚、原生亮度参数和全部牌面映射测试，共 75 项。

浏览器检查覆盖设置交互、320／360／390／430／768／1024 px 布局、三套牌面、图片保存与重启恢复、外观方案导入导出、错误文件、存储写入失败、默认外观重置不影响对局、启动页和清空全部数据。原有 84 篇教材的阅读、搜索、自测、图片缩放、阅读位置恢复及资源加载检查通过；牌效、何切、清一色练习及五种宽度回归通过。

Android 12 模拟器从 1.8.0 成功覆盖安装，升级前 14 张手牌与 1300 点计算结果保留；已验证深色主题、系统文件选择器导入背景、62% 窗口亮度与常亮标志，强制关闭后重新打开仍能恢复主题、亮度和背景。未进行真实手机测试。

## 源码与构建

项目仍为离线 HTML／CSS／JavaScript 与 Android WebView 外壳，没有新增前端构建步骤。打开 `index.html` 可预览；图片存储建议通过本地 HTTP 服务或 Android 安装版测试。

新增文件：`settings.js`、`settings-ui.js`、`settings.css`、`tiles-soul.png`、`tests/appearance.test.js` 和本说明。资源来源与映射见 `docs/appearance-assets.json`。

```powershell
node --test tests/*.test.js
```

Android 按 `android/build.ps1` 的参数指定 JDK、Android Build Tools、android.jar、构建目录、APK 输出和已有签名文件。私钥与密码不随源码包分发。
