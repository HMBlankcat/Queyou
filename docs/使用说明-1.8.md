# 学习栏目与完整收录说明 · 1.8.0

作者：HMBlankcat。更新日期：2026-11-16。

## 在哪里阅读

底部「学习」进入独立书架。原先的新手指南保留在书架的「简明新手指南」入口；对局、看牌算分、牌谱、役种和练习仍在原有位置。

书架提供两套完整教程、全文搜索和「继续阅读」。进入教程后可查看分组目录，阅读器支持切换章节、跳到本篇小节、15–23 px 字号、上一篇／下一篇和手动已读标记。表格在自己的边框内左右滑动；点击配图或原书页后，使用＋／－放大并上下、左右拖动。

「已读」只记录阅读行为，不表示已经掌握。课内选择题可直接选择、核对并查看原参考答案及判分依据；开放题和练习册按原文配合纸笔作答，再展开或打开参考解。没有把这些记录记入真实对局，也不会用阅读量判定麻将水平。

## 原稿与完整性核对

初始源为用户提供的 TeX 与配套 PDF。进阶源为 StudyMate 导出的 data.js。该导出包含课程正文和题库，但练习册只附链接及文件名，因此从同目录的原 subject 文件夹补齐对应的 Markdown 练习、参考解和已保存资料。补充前逐一确认 23 节原文和练习册说明与导出内容完全相同。

`docs/learning-sources/` 保留原始 TeX、PDF、导出数据、课程 Markdown、题库 JSON、练习册、答案和资料原文。它们是核对用的数据，没有运行其中的 shell、Python 或其他工作流指令。备课计划、学生遥测、工具程序和原导出页面的 React 实现不作为教学内容混入正文。

`tools/import-learning.py` 对初始 TeX 使用有限命令转换：未知命令和环境会中止，不会静默删除内容。只略去字号、颜色、页边距和留白等排版控制；原页同时完整保留。Markdown 禁用原始 HTML 执行，所有内部材料链接必须解析到实际收录单元，所有题库锚点必须得到对应题目。配图原文件不压缩。

`docs/learning-content-audit.json` 记录内容计数、各原文件 SHA-256、各阅读单元哈希与文本长度。`tools/check-learning-coverage.py` 用独立的 Markdown token 遍历和 TeX 文本片段核对，已通过 5557 段正文、表格、公式与完整代码块的保留检查。`tests/learning.test.js` 另外核对原题库、术语、目录顺序、本地链接和离线字体。

## 资料形式与署名

外部来源网页保留为参考链接，点击时需要网络；安卓中由系统浏览器打开。已保存的资料附录可离线阅读。其中《Riichi Book I》原本保存的是完整 LaTeX 源码，App 按原始代码块展示，并保留“外部图引用未渲染”的来源说明，不把缺少的外部书页或图片补造为原文。两套教程本身及其提供的全部配图均有可直接阅读的正文。

《Riichi Book I》资料保留 Daina Chiba 署名、原址和原稿的 CC BY-NC 3.0 许可说明；这些材料不因进入本项目而改为 App 代码的许可。KaTeX 与其字体的许可证位于 `docs/learning-licenses/`。教程及原用户资料的权利归对应作者。

## 本地记录与清理

书架底部「清除本栏阅读与自测记录」清除学习栏的位置、已读标记、课内选择题记录和阅读偏好。牌谱中的「清空全部本地数据」也包含上述记录。清除记录不删除 APK 内置教材，因此清理后仍能完整离线阅读。教程正文和图片不重复写入 localStorage。

原有对局备份继续用于对局数据；学习栏的阅读位置与课内答题记录仅保存在本机，不随原有对局备份导出。

## 开发和验证

直接打开 index.html 或通过本地 HTTP 服务运行，无前端构建步骤。重新导入需要 Python 的 markdown-it-py、mdit-py-plugins、beautifulsoup4、Pillow，以及 Poppler 的 pdftoppm：

```powershell
python tools/import-learning.py --beginner '<初始教程目录>' --advanced '<StudyMate export目录>' --supplement '<对应 subjects/mahjong-soul目录>'
python tools/check-learning-coverage.py
node --test tests/*.test.js
```

Android build.ps1 从 learning-assets.json 复制全部学习资源，沿用仅允许平面 ASCII 文件名的资源路由，补充 WOFF2 字体 MIME；没有添加联网权限。版本为 1.8.0 / versionCode 9，使用原签名，可覆盖安装。

验证包括原有 64 项规则／记账／练习测试及新增 5 项内容测试、独立原文覆盖检查、84 个阅读单元的浏览器交互和资源检查、320／360／390／430／768 像素布局、阅读恢复、图片缩放、内链与清理，以及旧版牌效／何切／清一色练习回归。README 保持原样。

Android 12 模拟器已从 1.7.0 成功覆盖安装到 1.8.0，核验学习书架、目录、正文阅读和返回操作；升级前的 14 张算点输入仍保留。没有进行真实手机测试。
